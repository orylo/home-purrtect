# assets — 그림(스프라이트) 폴더

여기에 1930년대 카툰풍 스프라이트(치즈·적·배경 등)를 넣습니다.

지금은 개발 중이라 임시 컬러 사각형으로 동작을 먼저 만들고,
그림이 준비되면 이 폴더에 넣어 하나씩 교체합니다.

추천 하위 구조(나중에):
- `assets/sprites/cheese/` — 치즈 모션(walk, jump, shot, hit ...)
- `assets/sprites/enemies/` — 적(쥐, 바퀴벌레, 박쥐 ...)
- `assets/backgrounds/` — 막별 배경(담벼락, 마당 ...)
- `assets/ui/` — 버튼·아이콘 등
