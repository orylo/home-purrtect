## 0. 도감의 두 영역
직업 카드는 **두 영역**으로만 관리한다. (마케팅 카피는 직업 단위가 아니라 게임 단위라 도감에 두지 않는다 — 폐기.)
- **■ 게임 내 노출** — 플레이어가 도감/전투준비 UI에서 실제로 읽는 글. 아래 UX 라이팅 철칙(§1)을 반드시 따른다.
- **■ 내부용** — 개발·기획용 메모(비노출). 설계 의도·밸런스·합성 전리품·수치 출처·아트 노트.

## 1. UX 라이팅 철칙 (게임 내 노출 = 반드시 준수)
유저가 읽는 글이다. "쓰는 사람이 아는 것"이 아니라 "읽는 사람이 한 번에 이해하는 것"이 기준이다.
1. **정보 위계를 줄바꿈으로 가른다.** 직업명 / 등급 / 정체성 / 설명을 각각 다른 줄·블록으로 분리한다. 한 줄에 여러 정보를 욱여넣지 않는다(오독 방지). 위치로 구분되면 라벨("직업명:" 등)은 굳이 붙이지 않는다.
2. **한 줄(정체성) ≠ 상세 설명, 역할을 가른다.**
   - **정체성(한 줄)** = 전투와 무관. *그 직업이 누구인지* — 세계관·출신·성격.
   - **상세 설명** = *어떻게 싸우는지* — 무게중심·강점·플레이 감각. 세계관 톤의 서술로.
3. **항목은 `라벨 : 값` 한 줄로.** "크게 한 방, 묵직하게 강타"처럼 라벨 없이 값만 뭉치지 않는다. → `치명타 효과 : 크게 한 방, 묵직하게 강타`. 읽는 사람이 뭐가 뭔지 즉시 알게 한다.
4. **블록 사이에는 빈 줄을 넣는다.** 치명타 효과 / 스킬 / 다음 등급은 서로 붙지 않게 한 줄 띄운다(마크다운에서 줄만 바꾸면 한 줄로 붙어버림).
5. **무기는 짧은 서술체("~한다").** 괄호 보충 설명 금지(지저분하고 굳이 필요 없는 정보가 많다). 예: `권총을 뽑아 직선으로 쏜다`.
6. **장점 중심으로 쓴다.** 모든 직업이 매력적으로 보이게. 단점을 굳이 강조하지 않는다. 단, **불발처럼 카툰적이고 귀여운 약점은 캐릭터성으로 OK**("아직 서툴러서 불발이 난다").
7. **줄임말·전문용어는 풀어쓴다.** "크리율" → **치명타 확률**, "크리 효과" → **치명타 효과**. 유저가 바로 이해하는 말로.
8. **성 중립.** 직업은 장비일 뿐 성별 정체성이 아니다. "하녀" 같은 성별 한정 표현 대신 "일꾼" 등 중립어.
9. **군더더기를 뺀다.** 모든 직업에 공통이라 굳이 안 써도 되는 말은 제거(예: 스킬은 전부 사서 장착하므로 "사서 장착" 안 씀).
10. **노출 최소주의.** 게임 내 노출엔 *플레이에 필요한 것*만. 합성 전리품·내부 수치 출처·설계 의도·스토리 스포일러는 전부 내부용으로 내린다.
11. **'레벨' 단어 미노출.** 내부 데이터는 Lv1~5지만, 유저에겐 **등급 라벨**(이름 없는 → 떠오르는 → 소문난 → 이름난 → 전설의)으로만 보인다. "레벨"이라 쓰면 연속·자동 상승처럼 보여 오해를 부른다(실제론 등급별 합성 승급).
12. **직업명은 헤더에 한 번만.** 헤더로 직업명을 띄웠으면 본문에서 다시 굵게 반복하지 않는다.

## 2. 카드 포맷
### ■ 게임 내 노출 (이 순서·이 형식 고정)
```
## (직업명)              ← 헤더, 한 번만
(등급 라벨)              ← 등급 없으면 "등급 없음"
(정체성 한 줄)           ← 전투 무관, 누구인지
(상세 설명)              ← 어떻게 싸우는지, 세계관 톤 2~3문장
**무기**
- 근접 : ~한다
- 원거리 : ~한다
(스탯 표: 체력 / 원거리공격력 / 근거리공격력 / 공격속도 / 이동속도 / 치명타 확률)
**치명타 효과** : (값)
**스킬** : (3종 이름) / 또는 "없음"
**▸ 다음 등급** : 전리품을 모아 (다음 직업명)〈(다음 등급)〉으로 합성
                  ← 합성 사슬 있을 때만. 단일 고정이면 이 줄 생략.
```

```
- 패밀리 : (직업 패밀리명 / 등급 사슬)
- 사슬 위치 / 길이 : (몇 단계 / 풀 5단·단일 고정 등)
- 획득 : (어디서 어떻게)
- 다음 등급 합성 전리품 : (이전 등급 장비 + 동전 + 전리품 / 〔TBD〕)
- 설계 의도 : (로스터 역할·왜 이렇게)
- 밸런스 메모 : (근접 타겟 수·사거리·불발률·스킬 역할 등)

- 아트 노트 : (일러스트가 담을 것)
```

## 3. 공통 규칙 (전 직업 적용)
- **카드 단위 = 등급별 별개.** "견습 보안관"과 "부보안관"은 서로 다른 카드(다른 장비). **각 등급은 0/1개**(중복 없음).
- **성장 = 합성 승급(2026-06-04 확정), 레벨업 아님.** 다음 등급 = **직전 등급 장비 + 동전 + 전리품** 합성 → 합성 시 **직전 등급은 소모**. 보유 중이면 제작 잠금·미보유면 제작 가능, 레시피는 영구(재제작 가능). 합성 사슬이 없는 단일 고정 직업도 있다(길냥이). (관리 규칙 = `기획_자산관리_전투준비.md` §2)
- **등급 라벨(공통, 유저 노출):** 이름 없는 → 떠오르는 → 소문난 → 이름난 → 전설의. (내부 Lv1~5 / 배율 1.0·1.5·2.2·3.2·4.5)
- **직업명은 단계별로 따로**(견습 보안관 → 부보안관 → …). 등급 라벨은 그 아래 공통으로.
- **근접 평타 최대 타겟 = 직업별.** 메이드만 **3마리**, 그 외 전 직업 **2마리**(사거리 300px).
- **스킬 = 직업당 3종, 동전으로 사서 슬롯에 장착.** 1막은 슬롯 2개. 1·2·3번째 모두 1막 판매(1-9 / 1-15 / 1-17)지만 **슬롯이 2개라 3개 중 2개만 장착**(3번째 슬롯은 Lv3=2막에 열림).
- **수치의 단일 진실원천(SSOT) = 코드(`game_state.gd`).** 도감의 스탯 숫자는 코드 기준으로 갱신. 밸런스 튜닝되면 도감도 따라 고친다.

## 길냥이
등급 없음
비 오는 거리에서 혼자 살아남은 길고양이.
거리에서 익힌 싸움법이 전부다. 무기랄 게 없으니 코앞의 적은 주먹으로 후려치고, 멀찍이 있는 놈에겐 돌을 집어 던진다. 그마저도 주먹 쪽이 더 매서워, 어지간하면 바짝 붙어 치고받는 편이 낫다. 변변한 한 벌을 갖추기 전까지, 맨몸으로 버텨내는 치즈의 출발점.
**무기**
- 근접 : 무기가 없어 주먹을 휘두른다
- 원거리 : 길거리에서 주운 돌멩이를 집어 던진다

|---|---|
| 체력 | 80 |

| 근거리공격력 | 8 |

| 이동속도 | 1.0 |

**스킬** : 없음

### 견습 보안관

## 견습 보안관
이름 없는 등급
담장 옆 궤짝에서 주운 배지로 갓 보안관 흉내를 내기 시작한 풋내기.
권총과 곤봉을 둘 다 다루는 올라운더다. 멀리는 총으로 쏘고 코앞은 곤봉으로 후려치는데, 어느 한쪽도 빠지지 않아 어떤 상황에서도 든든하게 버틴다. 체력도 가장 두둑해, 뭘 해야 할지 모를 땐 일단 보안관이 답이다. 다만 아직 총솜씨가 서툴러, 이따금 총알이 불발로 픽 떨어진다.
**무기**
- 근접 : 곤봉을 휘두른다
- 원거리 : 권총을 뽑아 직선으로 쏜다
| 스탯 | 값 |
|---|---|
| 체력 | 140 |
| 원거리공격력 | 13 |
| 근거리공격력 | 11 |
| 공격속도 | 0.8 |
| 이동속도 | 1.0 |
| 치명타 확률 | 15% |
**치명타 효과** : 크게 한 방, 묵직하게 강타
**스킬** : 경고 사격 / 방패 자세 / 지원 요청
**▸ 다음 등급** : 전리품을 모아 **부보안관**〈떠오르는 등급〉으로 합성
#### ■ 내부용
- **패밀리** : 보안관 (사슬: 견습 보안관 → 부보안관 → 보안관 → 주 보안관 → 보안관장)
- **사슬 위치 / 길이** : 1단계 / 풀 5단(이름 없는~전설의)
- **획득** : 1-3 클리어 후 담장 옆 궤짝에서 발견(노획형, 첫 직업)
- **다음 등급 합성 전리품** : 부보안관(2등급) = 견습 보안관 + 검은쥐 털×10 + 단추×3 + 옷핀×2 + 코인 1,000 (1-19 해금). 3~5등급은 2막 재료 TBD(자산관리 §2.5)
- **설계 의도** : 게임의 기둥·입문. 근·원 균형, 체력 최고(탱커 쪽). 치명타=특수효과 없는 순수 강타라 초보가 이해하기 쉬움. 불발 12%는 "서툰 풋내기" 설정으로 정당화(상위 등급에서 줄일 여지).
- **밸런스 메모** : 원거리 권총=직선·끝까지·불발 12%. 근접 최대 2마리(300px). 스킬 풀(경고 사격=제어 / 방패 자세=생존 / 지원 요청=광역딜, 3개 모두 1막 판매·슬롯 2개라 택2).
- **수치 출처(SSOT)** : `game_state.gd` = 140 / 13 / 11 / 0.8 / 1.0 / 15%
- **아트 노트** : 별 배지·챙 넓은 모자·권총집·곤봉. 정의로운 척 능청. 컵헤드/러버호스. 등급 사슬은 같은 실루엣에 장비 디테일·색만 격상(리스킨).
