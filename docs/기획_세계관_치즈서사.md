> **이 문서의 역할**: 기획 챗(claude.ai)에서 새로 정한 *서사 청사진*. 전부 "아직 구현 안 된 미래 설계"이며 STATUS.md(현실)와는 무관.
> **Code 작업 가이드**: 이 문서는 `docs/기획_세계관_치즈서사.md`로 분리 저장. 브리프(`기획_브리프.md`)의 §2 세계관 / §5 5막 / §6 캐릭터 / §6-B 컷신과 상호 참조. **컷신·대사 풀 디테일(2막 이후)은 아직 안 했음 → 다음 단계.**
> **태그 규칙**: `[확정]` = 합의됨, 그대로 반영. `[열어둠]` = 방향만, 확정 금지(후보/원칙만 보존).
> **연결**: `기획_펄로맨스.md`(거울 4인 구조·펄↔치즈 상호 회수), `기획_홈인터랙션.md`(특이점·이방인 디테일이 다마고치 모드에 표시).

## 0. 한눈에 — 이번에 정한 것

1. **치즈에게 "상처"를 부여** — 능력이 아니라 *과거의 상실*로 유저 애착을 만든다.
2. **라이벌이 둘**: 펑거스(처지 뒤바뀐 거울) + 쉐도우(같은 출발, 정반대로 자란 거울). 쉐도우는 **6막 조건부**.
3. **막을 관통하는 두 사다리**: 소문→전설(논리) + 펑거스 비극(감정). 여기에 치즈 과거·쉐도우 미스터리가 가닥으로 더해져 **여러 줄기를 땋아** 진행.
4. **5막은 6막 없이 100% 완결.** 6막은 완결을 덮어쓰지 않고 *위에 얹히는* 추가 콘텐츠.
5. 치즈의 "특이점"(습관 또는 소품) — **있다는 것만 확정**, 정체는 열어둠(코스튬 무간섭 조건).

## 1. 치즈 서사 — 다섯 기둥

치즈는 **전 구간 무대사** `[확정, 기존]`. 말을 안 하므로 백스토리는 전부 *사일런트로 전달 가능한 형태*(회상 컷·반응·환경·습관)로만 설계. 유저가 치즈에 자기를 투영하게 하는 핵심 장치.

### 기둥 1 — 상처: "두고 온 누군가" `[확정]`
- 저택 이전, 어린 치즈는 비 오는 거리의 **종이박스 집**에서 *혼자가 아니었다.* 닮은 길냥이 하나와 박스를 나눠 썼다.
- 어느 비 오는 밤, **재난(트럭/홍수 등 — 톤에 맞는 사고)**으로 둘이 갈렸다. 화면엔 그 애가 *휩쓸려 사라지는 것까지만.* **죽음을 명시하지도 부정하지도 않는다**(시신·확정 사망 묘사 없음).
- 치즈는 그 애가 **죽었다고 믿는다.** 그 직후 검은 우산(영감)이 치즈를 거둔다 → *상실 위에 거둬짐이 얹혀* 더 짠함.
- 그래서 저택을 지키는 건 단순 밥줄 사수가 아니라 **"다시는 무엇도 잃지 않겠다"는 속죄.** 매 웨이브 라인을 버티는 게 곧 그 빗속 밤을 다시 쓰는 행위 → 코어 루프 전체에 의미 부여.
- *(헤어진 그 애 = 형제냐 친구냐는 **의도적으로 명시 안 함** `[확정]`. 닮은꼴+무대사라 유저가 알아서 "형제"로 읽음. 확정하면 오히려 좁아짐.)*

### 기둥 2 — 특이점(습관 또는 소품): "뭔가 하나가 있다" `[열어둠]`
- **확정된 것**: 치즈에겐 *특이한 무언가*가 있다. idle / 다마고치 모드에 **종종** 등장(상시 노출 X).
- **조건(이건 확정)**: ① **몸에 걸치지 않음** → 코스튬 레이어와 100% 무간섭(코스튬 多). ② 외형 슬롯이 아니라 *서사/연출 요소*. ③ 막 진행·펄 호감도에 따라 **옅어질 수 있게**(허브에서 보이는 성장 아크).
- **폐기**: 병뚜껑 = 메타포 약해서 **폐기.** 목줄/끈/사진 등 *몸에 차는 유품류*도 코스튬 충돌·진부로 **보류.**
- **후보(미확정, 다음에 택1 또는 조합)**:
  - *(행동형, 추천)* **달 보며 욺** — 밤이면 창밖 달 보고 야옹. 길거리에서 밴 외로움. 안정될수록 횟수↓, 엔딩/6막엔 안 욺(또는 같이 봄). 코스튬·UI 완전 무간섭, 정서 훅 최강.
  - *(행동형)* **숨겨둔 비상식량** — 안전한데도 곳곳에 먹이를 쟁임(생존 본능). "이제 안 숨겨도 돼"로 회수.
  - *(행동형)* **구석잠** — 푹신한 방석 줘도 좁은 구석/박스에서 잠.
  - *(물건형)* **빈 깡통/박스 조각** — 옛 박스 시절 흔적. 다마고치에서 그 안에서 잠. (6막 쓰면 쉐도우가 알아보는 고리로 쓸 여지.)
- **원칙**: 소품은 *필수가 아니라 보강재.* 없어도 상처는 프롤로그+게임오버+무대사 반응으로 선다.

### 기둥 3 — 발길질의 재해석: 야망이 아니라 **공포** `[확정]`
- 프롤로그에서 치즈가 펑거스를 걷어차는 행위 = *출세욕*이 아니라 *공포.* 막 지붕을 얻은 순간 "또 집을 잃을지 모른다"는 트라우마 + 영감의 "쥐 한 마리라도 들이면 끝" 경고가, 그 쥐를 *생존의 위협*으로 만든다.
- 즉 치즈는 **훗날 펑거스가 느낄 바로 그 노숙 공포**에 떠밀려 저질렀다. 순간은 코믹하게(개그 유지), 의미는 후반에 비극으로. → 치즈가 기회주의자가 아니라 *흠 있지만 사랑스러운* 캐릭터가 됨 + 펑거스 거울이 정확히 맞물림.

### 기둥 4 — 영원한 이방인: 집에서도 안 편한 치즈 `[확정]`
- 홈 허브에서 사일런트 디테일로: 비단 방석 대신 **문 옆 낡은 박스에서 잠**, 초인종/전보에 움찔, 먹이를 쟁임 등 길거리 본능.
- **막이 지날수록 긴장이 풀린다** — 박스가 안쪽으로 옮겨가거나 습관이 옅어짐 = *허브에서 눈에 보이는 성장 아크*(저비용 고효율). "넌 가족이야" 반전을 터지게 하는 밑밥(그는 늘 전보 한 장 차이로 길바닥이라 믿으니까).

### 기둥 5 — 스테이크: 유저 = 치즈의 의지 `[확정]`
- 무대사 + 플레이어 조작이라, 유저는 영웅을 *구경*하는 게 아니라 *겁먹은 작은 길냥이를 라인에 세워두는 의지 그 자체.*
- 게임오버 = **빗속으로 다시 내던져짐**(프롤로그 상실이 만든 바로 그 공포). 라인을 지키는 것 = "널 다시 비로 보내지 않겠다"는 유저의 거부.

### 통일 모티프 — **비 vs 온기** `[확정]`
- 비 = 노숙/취약/상실(박스 잃은 밤·길거리·게임오버). 따뜻한 불빛 = 소속.
- 6막 유무 양쪽에 다 작동: 안 나오면 "비에 잃었고 온기로 품었다", 나오면 "비에 잃은 걸 끝내 온기로 되찾았다."

## 2. 라이벌 거울 구조 — 펑거스 + 쉐도우

거울이 **두 겹**이다. 둘 다 "이 집/이 행복에 속하고 싶었다"는 같은 갈망의 변주.
> **펄 포함 4인 통합 거울표는 `기획_펄로맨스.md` §7 참조** (펑거스·펄·쉐도우·치즈 = "가면 ↔ 진짜"의 변주).

### 펑거스 (1~5막 메인 라이벌) `[확정, 기존 + 보강]`
- *처지가 뒤바뀐* 거울. 원래 집에 살다 치즈에게 쫓겨남 → 모든 침공의 숨은 근원.
- 표적 = **"이 집"**(소유·귀향).
- 5막에서 "거울상도 결국 속하고 싶었다"로 화해 → 저택 식구로.

### 쉐도우 (6막 빌런 → 화해, **조건부**) `[확정 방향 / 세부 열어둠]`
- *같은 출발점에서 정반대로 자란* 거울. 치즈는 거둬져 따뜻해졌고, 쉐도우는 살아남되 모진 길을 걸어 악해짐. **"사랑받은 길냥이 vs 사랑받지 못한 길냥이."**
- **= 프롤로그에서 잃은 그 애.** 죽은 줄 알았으나 살아서, *적이 되어* 돌아옴.
- **외형 `[확정]`**: 치즈와 똑 닮음 + 색이 조금 다름(어둡/탁한 톤) + **한쪽 귀가 잘림** + 흉터·날카로운 눈(악한 인상). 실루엣은 같아서 *보는 순간 유저가 "어?" 하고 알아챔* → 무대사로 즉시 전달.
- **표적 = "네 행복"**(관계·질투의 사무침). 펑거스(집)와 안 겹침. 치즈 *개인*을 겨냥해 더 사무침.
- **첫 등장 비트 `[확정]`**: 침묵 → 인식 → 폭발. ① 무대사 한 박자(닮은꼴이 나타나 치즈 동공 지진) → ② 대사 폭발:
  > **"너만 그렇게 행복하게 사니까 좋냐? 난 그날 이후 하루도 편한 날이 없었어. 절망과 고통뿐이었어!!"**
  - (5막에서 막 "가족·사랑·안정"을 완성한 직후라, 그 행복이 *무기로 되돌아옴.* 죽은 줄 안 애가 살아서, 첫마디가 원망 → 충격+죄책감+반가움이 한꺼번에.)
- **화해 문법 `[확정]`**: 싸워 이겨서가 아니라, 치즈가 **"널 한순간도 안 잊었다"를 증명**하는 순간 무너짐. 펑거스 화해와 같은 문법의 *형제 버전*으로 더 사무치게. → 최종적으로 펑거스+쉐도우 **둘 다 저택 식구.** 외톨이 영감의 집이 *길에서 온 것들의 안식처*가 되는 게 시리즈 도착점.
- **이름**: 가칭 **쉐도우(Shadow)** `[열어둠]` (치즈=밝음 ↔ 그림자·잘린 귀).
- **6막 등장 동기 `[열어둠]`**: 어떻게 다시 나타나는지 미정. 원칙은 **"죽었어도 살았어도 말이 되게."** 후보: (가) 소문→전설이 우주까지 퍼져 쉐도우도 어딘가서 들음(소문 엔진이 *상실을 되돌리는 도구*로 반전 — 시적) / (나) 다른 집·세력의 수문장이 됨("같은 운명, 다른 주인" — 거울 제일 깨끗) / (다) 펑거스가 끌어온 마지막 패. → 1차 출시 반응 보고 결정.

## 3. 막을 관통하는 두 사다리 (+ 추가 가닥)

### 사다리 A — 소문→전설 (논리 엔진: 적이 미쳐가는 *명분*) `[확정]`
적이 쥐→외계인으로 뛰는 건 "그냥 세짐"이 아니라 **치즈가 유명해진 대가**다.
- 1막 동네 입소문 → 2막 야생/신문 1면 → 3막 **인간 범죄계가 "보물"을 믿음** → 4막 라디오 송출로 전설이 *초현실*로 변질 → 5막 **방송이 우주까지** = 외계인.

### 사다리 B — 펑거스 비극 (감정 엔진, 진짜 척추) `[확정]`
- 1막 코믹 빌런(비웃음) → 2막 *유능한 꾼*임이 드러남 + 첫 연민 → 3막 자기 패거리(인간)에게 **다시 걷어차임**(최초 발길질의 거울) → 4막 자기가 부른 게 통제 불능 + **잠깐 치즈와 공조(적의 적)** → 5막 거울상 진실 + 화해.
- 핵심: 5막 반전이 갑툭튀하지 않게, **2막부터 야금야금 연민을 적립.**

### 추가 가닥 — "여러 줄기를 땋는다" `[확정]`
위 두 사다리에 **치즈 과거(상처 드립)** + **쉐도우 미스터리(조건부)**가 얹혀 막마다 짝을 이룬다:

| 막 | 펑거스(B) | 치즈 과거 드립 | 비고 |
|---|---|---|---|
| 프롤로그 | 걷어차임(코믹) | **빗속 상실** — 닮은 애 사라짐(유저는 죽음으로 읽음), 직후 거둬짐 | 쉐도우 씨앗 심기 |
| 1막 | 코믹 빌런 | 영원한 이방인 확립(문 옆 박스 등) + 특이점 슬쩍 등장 | |
| 2막 | 유능한 꾼 + 첫 연민(추운 밤, 불 켜진 창 바라봄) | 박스에 *누군가 함께였다*는 첫 힌트(회상 한 조각) | |
| 3막 | 패거리에게 걷어차임 | 치즈가 *왜* 걷어찼는지(공포) 재맥락 + 죄책감 한 번 깜빡 | 1차 완결 |
| 4막 | 통제 불능 + 공조 | **상실의 진실 풀 공개** — 집착이 비로소 이해됨(가장 무거운 비트) | |
| 5막 | 화해 → 식구 | 비/온기/특이점 **회수**. 가족·자리 채워짐 — 단 *사라진 그 애 자리*는 **미세한 빈자리**로 남김 | 6막 떡밥(안 나와도 '품은 평화'로 닫힘) |
| **6막**(조건부) | (펑거스는 말리는 쪽 등으로 재배치 가능) | 쉐도우 = 그 애. **빈자리에 응답** → 부활·화해 | 추가 콘텐츠 |

## 4. 막별 정체성 (2~5막) — 한 문장 + 핵심 비트 `[확정 방향 / 컷신·대사 풀 디테일은 다음 단계]`

> 1막 테마 = "라이벌 구도 깔기 + 치즈 불쌍 + 튜토리얼". 아래는 그 결을 끝까지 끌고 가는 막별 정체성.
> **막 설계 공식**: ① 감정 테마 ② 펑거스 관계 한 칸 전진 ③ 소문→전설 한 단계 ④ 새 기믹/적 1개.

- **2막 — 마당·정원 / 야생동물 / "위협이 진짜가 되고, 펑거스가 광대가 아님이 드러난다"**
  - 펑거스가 직접 안 싸우고 *야수를 꼬셔옴*(보물을 미끼로 협상 = 펑거스도 소문을 믿는 자임을 깔기). 첫 연민 비트(해질녘, 추위에 떨며 불 켜진 창 바라봄).
  - 새 기믹: 두더지(땅에서 솟음 → "적은 오른쪽에서만 온다" 규칙 깨기), 까마귀(공중), 분수/스프링클러 물 위험, 낮→해질녘 조명. 시스템: **라쿤 상점 + 닌자 첫 등장(2-1)**. 끝에 인간 그림자(3막 떡밥).

- **3막 — 현관·거실 / 인간 도둑 / "소문이 전설이 돼 사람까지 끌어들인다 + 코미디 절정 + 1차 완결"**
  - 사다리 A 최대 페이오프(인간이 보물을 믿음). **함정 슬랩스틱**(페인트통·다리미·구슬 = 설치형 소모품 도입). 펑거스가 길잡이로 합류했다가 도둑 두목에게 *"비켜, 쥐새끼"* 하고 걷어차임 = 1막 치즈 발길질의 거울.
  - 1차 출시 엔딩 → 카타르시스: 영웅 대관 신문 몽타주 + 펄 로맨스 마일스톤 + 따뜻해진 영감 전보 → **초록 섬광(외계 떡밥).** 마지막 컷, 축하받는 집을 추운 밖에서 보는 펑거스(쌉싸름).

- **4막 — 주방·침실·다락 / 초현실 코믹호러 / "전설이 미쳐 날뛴다 + 펑거스 비극 정점 + 공조"**
  - 현실→비현실 전환점(컵헤드식 괴물). 펑거스가 부른 게 통제 불능 → *자기가 되찾고 싶던 집이 박살날 위기.* "적의 적" 비트(치즈+펑거스 잠깐 등 맞대고 싸우고 어색하게 헤어짐, 무대사로 "우린 둘 다 그냥 여기 살고 싶었을 뿐").
  - **치즈 상실의 진실 풀 공개**(가장 무거운 비트). 끝: 라디오가 전설을 우주로 송출.

- **5막 — 최심부·지하 금고 / 외계인 + 펑거스 최종 / "부조리의 정점 → 진실 → 가족 → 거울상의 화해"**
  - 방송이 우주까지 닿아 외계인이 보물을 캐러 옴(소문→전설의 펀치라인). 금고 = **유언장+입양 서류** → 보물은 *소속감*, 곧 치즈 자신.
  - 영감 귀환·첫 얼굴·**"넌 가족이야."** 펑거스 화해(식구로). **단 '사라진 그 애' 자리는 미세한 빈자리로** → 6막 조건부 떡밥. **6막 없이도 완결**(빈자리는 '품은 평화'로 닫힘).

## 5. 6막 (조건부 — 쉐도우) `[확정 원칙 / 세부 열어둠]`

- **대원칙**: 5막 엔딩은 6막 없이 **100% 완결.** 6막은 완결을 부수지 않고 *위에 얹힌다.* (브리프 §11 "5막 완결 + 끝나지 않는 층" 원칙과 일치.)
- **슈뢰딩거의 친구**: 5막에서 죽음을 명시도 부정도 안 함 → 안 나오면 자연스럽게 죽은 것, 나오면 추가 콘텐츠로 살아 돌아온 것. 둘 다 말 됨.
- 같은 소품/연출이 두 가지로 읽힘:
  - **안 나오면**: 5막에서 *빈자리를 안고 살아가기로 한 평화* = 상실을 품은 안식. 그 자체로 닫힘.
  - **나오면**: 그 빈자리가 6막 오프닝에서 *응답* = 부활. 이전 엔딩의 의미를 *덮어쓰지 않고* 증폭.
- 화해 골격(§2 쉐도우 참조): 빌런 등장 → 왜 악해졌나(사일런트 회상 한 컷) → "한순간도 안 잊었다" 증명 → 무너짐 → 식구. 펑거스+쉐도우 둘 다 저택의 일원.

## 6. Code 작업용 — 연출/시스템 반영 포인트

- **프롤로그 컷신 재작성 필요**: 기존(입양+발길질)에 **빗속 상실 비트** 추가(닮은 애 사라짐 → 직후 거둬짐). 발길질을 *공포 동기*로 재맥락(개그 톤은 유지).
- **게임오버 연출**: "빗속으로 다시 내던져짐" = 프롤로그 상실과 시각적으로 운율(비 모티프).
- **홈 허브/다마고치 모드**: 영원한 이방인 디테일(문 옆 박스 잠 등) + 특이점(습관/물건) *종종* 등장. 막 진행·펄 호감도에 따라 **옅어지는** 상태 변화. → `기획_홈인터랙션.md`의 "기분/상태" 모델에 *상태 플래그*로 얹기(별도 시스템 X).
- **특이점은 코스튬 무간섭**: 몸에 걸치는 슬롯 금지. 연출/애니/다마고치 이벤트로만.
- **쉐도우 에셋(6막, 추후)**: 치즈 스프라이트의 *변주*(색 변경 + 잘린 귀 + 흉터/눈) → 제작 효율 좋음. 1차 출시엔 불필요, 프롤로그에 *씨앗 컷*만.
