# Home Purrtect (홈 퍼르텍트) — 시스템 & 밸런스 상세 설계서 (1막 빌드용)

> 이 문서는 "기획 브리프"를 보완하는 *제작 착수용 수치 설계서*다. 코어 루프·스토리 같은 상위 설계는 브리프를 참고.
> **중요:** 아래 모든 수치는 *논리적으로 일관된 시작점*이며, 실제 손맛·난이도는 반드시 플레이테스트로 조정해야 한다. 비율과 구조가 핵심이고, 절대값은 튜닝 대상이다.

## 0. 이번 결정 요약

- **용어 통일:** **막** = (1-1~1-20 묶음, 총 5막) / **스테이지** = (1-1, 1-2 같은 작은 단위). "월드"는 안 씀.
- **등급 라벨 = 내부 Lv.1~5 + 표시 이름(평판 계열).** Lv1 이름없는(Nameless) / Lv2 떠오르는(Rising) / Lv3 소문난(Renowned) / Lv4 이름난(Famed) / Lv5 전설의(Legendary). 천장 확장 시 Lv6+ 신화의(Mythic). *평판 형용사라 어떤 직업명에 붙어도 충돌 없음*("이름 없는 보안관", "전설의 메이드"). 세계관 척추(소문→전설)와 일치. UI에선 별/색 병행으로 순서 표시. (이하 본문은 내부 표기 Lv1~5 사용)
- **해금 타임라인(1막):** 1-3 보안관 Lv1 지급 → 1-5 펄 → 1-7 상점(직업 2종 추가, 스킬X) → 1-9 스킬 판매 → 1-13 치와와(동료) → 1-15 두번째 스킬 → 1-16 비둘기(동료) → 1-17 세번째 스킬 → 1-19 Lv2 직업 구매 가능. (상세 §6-A)
- **라쿤(특수 상인) 첫 등장 = 2막 시작.** 1막은 해금이 빽빽 + 맥스(상시)에 먼저 익숙해진 뒤 등장해야 "특별한 손님" 임팩트. 2막부터 밀수 직업(닌자 등) 공급처와 타이밍 일치. 첫 등장은 스토리 이벤트, 이후 무작위 출현.
- **펄의 축복 = 3층 발전.** ① 가로(종류 확장): 막마다 새 축복 1~2종 해금. ② 세로(레벨 강화): 각 축복을 동전으로 레벨업(+10%→+15%→+20%). ③ 호감도: 막 진행·상호작용으로 쌓여 새 슬롯/강력 축복 해금, 5막 감정선과 연결. **단 축복은 "있으면 유리한 보너스"지 "없으면 불가"가 되면 안 됨**(필수화 금지).
- **플레이 타임:** 일반 스테이지 **1~2분**, 보스 **2~4분**. 콘텐츠 고갈은 *판을 길게* 늘려 풀지 말고(지루), *짧은 판을 다시 할 이유*(빌드 실험·파밍·점수·다른 직업)로 풀 것.
- **스킬 슬롯 수 = 2-2-3-3-4** (Lv1·2 = 2 / Lv3·4 = 3 / Lv5 = 4). 모바일 조작상 천장 4.
- **스킬 = 구매·장착식.** 직업에 자동 부여 아님, 동전으로 사서 슬롯에 끼움. 직업 귀속. 직업당 풀 3개(1막 기준), 슬롯에 골라 장착.
- **등급 ↔ 스킬 상호 보완:** Lv업과 스킬 구매는 전투력 두 축. "Lv1 + 좋은 스킬 ≈ Lv2 + 기본 스킬", 비용도 엇비슷.
- **등급은 강제 게이팅 아님.** 막마다 권장 Lv은 있으나, 한 단계 아래 + 좋은 스킬 + 실력으로 돌파 가능.
- **재화 = 단일 동전.** 노가다(파밍)로 벌거나 현금 구매. 돈으로 사는 건 *파워가 아니라 시간*. → P2W 아님.
- **현금 직접 판매 = 프리미엄 직업(다르게 놂·멋짐) + 코스튬 + 광고 제거.** 스킬·Lv은 동전으로만.
- **간판 3종(전부 Lv1~5 풀 라인):** **보안관**(균형·입문, 곤봉+권총) / **메이드**(근접 주력, 빗자루 넉백+접시 보조) / **음악가**(원거리 평타 주력+제어). 군인·권투·카우보이 대신 *시대·저택 배경에 더 맞는* 3종으로 교체.
- **모든 직업은 근접·원거리 평타를 다 보유**, 어느 쪽이 센지가 직업마다 다름(메이드=근접↑, 음악가=원거리↑, 보안관=균형). 스탯 5칸의 원거리/근거리 공격력 배분으로 표현.
- **크리티컬 = 직업 개성 표현 장치.** 평타엔 약한 기본효과, *크리 터지면 그 직업다운 강효과*. 메이드 크리=강넉백(저 멀리 날림), 음악가 크리=잠시 스턴, 보안관 크리=큰 데미지. **크리율은 직업 고정값**(스탯 칸 안 늘림). 스킬은 그 효과의 *확정 버전*(메이드=광역 강제 넉백, 음악가=범위 스턴 장판).
- **전투 공간 = 단일 화면 고정**(카메라 스크롤 없음). 왼쪽 끝=집, 오른쪽 끝=적 등장. 치즈는 화면 왼쪽~2/3 구간에서 좌우 이동. 적 전체가 항상 한눈에.
- **몸으로 밀기(공통 규칙):** 적은 "걷고-멈추기" 반복. **정지 중(속도0)이면 누구나 밀기 가능 / 전진 중이면 치즈 이동속도 > 적일 때만.** → 느린 직업도 *적 멈추는 타이밍 노려* 밀 수 있음(박힘 방지). **뭉침 저항 = 막힌 적 마릿수, 한계(예:3) 넘으면 못 밂**(무게 스탯 없음). 미는 동안 맞음 → 체력 트레이드오프. ⇒ *적 패턴(멈춤=밀 타이밍, 공격=점프 타이밍) 학습이 실력.*
- **이동속도 폭 확대(체감 위해):** 0.7~1.7 구간. 느림(집사류)0.7 / 보통(보안관)1.0 / 빠름(메이드)1.15 / 매우빠름(닌자)**1.6**. 적도 0.6~1.8로 벌림(투척쥐 0.6 ~ 검은 롤러쥐 1.8). (1.0 vs 1.3은 체감 약해서 폐기)
- **점프 = 회피 전용.** 적을 통과시키지 않음(치즈는 살아있는 관문). 점프는 *공격 타이밍만* 흘려보내고, 착지하면 적은 그대로 앞에 있어 계속 싸움.
- **음악가 체력 110으로 상향.** 간판 3종은 원거리 특화여도 *몇 대는 버티는* 기본기. 셋 다 110~130 구간(보안관130/메이드120/음악가110). 생존력 극단은 조연(닌자 70)의 몫.
- 상점 오픈: 1-5(소모품) → 1-7(직업) → 1-9(스킬)로 세분. / 첫 직업: 1-3 **보안관 Lv1** 지급. / 탈것 직업 제외. / 방어력은 체력 통합(스탯 5칸). / 목걸이 → 동료 호출 슬롯(외형 없음), 상시 패시브는 세트 내장. / 세트 = 직업 × Lv(1~5).

## 1. 핵심 전투 수치 모델 (★ 밸런스의 심장)

### 1.1 전투 구조 재확인
치즈는 바닥 라인 위의 **살아있는 관문**이다. 적은 오른쪽에서 등장해 왼쪽(집)으로 전진하다가, **치즈에게 도달하면 멈춰서 싸운다(통과 불가).** 치즈의 HP가 0이 되면 그제야 적이 집으로 쏟아져 **게임오버.** 즉 **치즈 HP = 유일한 실패 게이지.**

**전투 공간 = 단일 화면 고정 (카메라 스크롤 없음).** 왼쪽 끝=집(후퇴 한계), 오른쪽 끝=적 등장. 치즈는 화면 *왼쪽~2/3* 구간에서 좌우 이동. 적 전체가 항상 한눈에 보임 → "다가오는 걸 보고 대응"하는 디펜스 손맛 유지. 공간이 좁아 *멀리 도망/순간이동은 부적합* → 거리 관리는 화면 내 미세 조정으로.

**점프 = 회피 전용.** 점프해도 적은 통과하지 않는다(관문 규칙). 적의 공격 *타이밍만* 흘려보내고, 착지하면 적은 그대로 앞에 있어 계속 싸운다. (잡몹 chip은 점프로 못 피함 → §1.2; 보스·정예의 큰 telegraph만 회피 대상.) 직업별로 *체공·무적 프레임*을 다르게 줄 수 있음(닌자 같은 고기동형은 회피 성능↑ 여지).

**몸으로 밀기 (공통 규칙).** 치즈가 전진하면 앞을 막은 적을 *몸으로* 민다(겹칠 수 없으므로). 단:
- **적은 "걷고-멈추기"를 반복한다.** 전진 단계(이동 중) ↔ 정지 단계(공격/대기)를 번갈아.
- **밀기 가능 조건:** ① *적이 정지 중(속도 0)이면 **누구나** 민다* (느린 직업도 OK). ② *적이 전진 중이면 **치즈 이동속도 > 적 이동속도**일 때만 민다* (속도 차에 비례해 밀림). → **느린 직업도 "박히지" 않는다**: 적이 멈추는 순간을 노려 야금야금 밀면 됨. 빠른 직업(닌자)은 적이 움직이든 멈췄든 자유롭게 밂.
- **뭉침 저항 = 막힌 적 *마릿수*.** 한계(예: 3마리) 넘게 쌓이면 못 민다(무게 스탯 없음, 마릿수로만). → 물량은 몸으로 못 뚫음, 사격으로 줄여야. *디펜스가 밀기로 깨지지 않는 안전장치.*
- **미는 동안 적과 붙어 *맞는다* → 체력 트레이드오프.** 체력 높은 직업(보안관·메이드)은 맞으며 밀 수 있으나, 물몸(닌자 70)은 붙으면 죽어 *맨몸 밀기 사실상 불가* → 무적 스킬(연막)로 안전하게 밀고 빠져야(§4.3-C).
- **결과 — 패턴 학습이 곧 실력:** *언제 적이 멈추는지(밀 타이밍)* 와 *언제 공격하는지(점프 타이밍)* 를 읽어야 함. 적마다 "걷고-멈추는 리듬"을 다르게 주면 개성이 됨(쥐=자주 멈춤·밀 기회 많음 / 롤러쥐=안 멈추고 직진·못 밀어 사격으로만 / 공중·원거리형=밀기 대상 아님). → 적 종류마다 *밀기·회피·사격 중 뭘 쓸지* 가 달라짐.

**밀기 구현 시작 수치 (튜닝 기준점 — 플레이테스트로 미세조정):**
- **미는 속도 = (치즈 이동속도 − 적 이동속도) × 1.0** (계수 1.0 시작). 적 정지 중이면 적 속도=0이라 치즈 이동속도만큼 쑥쑥, 전진 중이면 속도 차만큼 천천히.
- **막힌 적 마릿수 한계 = 3마리 (전 직업 공통).** 4마리째부터 못 밂(무게 스탯 없이 마릿수로만). *직업 차등은 일단 없음* — 필요 시 후속 조정.
- **겹침과 밀기 (2026-06-01 명확화):** 적끼리는 서로 *겹칠 수 있다*(빠른 적이 느린 적 추월, 공중↔지상 통과). 단 밀기 마릿수는 **"치즈에 직접 닿아 막힌 적"만** 카운트 → 겹쳐 쌓인 뒤쪽은 안 셈. 즉 겹쳐도 미는 건 **맨 앞 최대 3마리**. 공중 적(박쥐·벌·참새)은 밀기 대상 아님(높이 다름)이나 *치즈 라인은 못 넘음*(관문).
- **미는 중 데미지 = 별도 수치 없음.** 붙어있는 동안 닿은 적의 *평타가 정상 적용*될 뿐 → 체력 높은 직업은 맞으며 밀고, 물몸은 위험. **메이드 = 평타 약넉백 + 크리 강넉백 → 적극적으로 밀어내는 직업.**
- **적 걷고-멈추는 리듬 & 밀기 난이도:** 회색·검은쥐(맨몸)=자주 멈춤→밀 기회 많음 / 롤러쥐(이동 1.6~1.8, 거의 안 멈춤)=밀기 거의 불가→사격 강제 / 투척쥐·거미=멀리서 멈춰 발사(다가오지 않음) / 공중(박쥐·벌·참새)=밀기 대상 아님. → 적마다 *밀기·회피·사격 중 뭘 쓸지* 가 달라짐.

플레이어가 하는 일: ① 드래그로 거리 관리(뒤로 빠지며 사격 시간 벌기 / 앞에서 버티기), ② 탭 점프로 *큰 공격 회피*, ③ 자동 조준 사격으로 다가오는 적을 미리 솎기, ④ 쿨타임 스킬·소모품으로 뭉친 적 처리.

### 1.2 두 개의 핵심 공식

**① 처치 시간 (TTK, Time-To-Kill)**
```
TTK = 적 HP / 치즈 DPS
치즈 원거리 DPS = 원거리공격력 × 공격속도
치즈 근접 DPS   = 근거리공격력 × 근접 공격속도
```

**② 스택(쌓임) 모델 — 난이도의 본질**
적은 치즈 앞에 *쌓인다.* 웨이브의 스폰 간격을 `spawn_interval`이라 하면:
```
TTK < spawn_interval  → 다음 적 오기 전에 처치, 안 쌓임 (안전)
TTK > spawn_interval  → 적이 쌓임. 쌓이는 속도 = (1/spawn_interval − 1/TTK) 마리/초
                        쌓인 적 N마리 × 적 DMG = 치즈가 받는 초당 피해
```
**플레이어는 사격으로 스택을 녹이고, 스킬·폭탄으로 한 번에 줄이고, 점프로 큰 공격만 회피한다.** 일반 잡몹의 누적 피해(chip)는 점프로 못 피하므로 *DPS 관리*가 핵심이고, 보스·정예의 큰 telegraph 공격만 점프 회피 대상이다.

### 1.3 난이도 조절 노브 (이 4개로 모든 스테이지를 디자인)
1. **적 HP** ↑ → TTK ↑ → 스택 증가 (탱키 압박)
2. **스폰 간격** ↓ → 물량 압박 (스웜)
3. **적 DMG** ↑ → 스택당 피해 증가 (실수 페널티 ↑)
4. **적 이동속도** ↑ → 사격 가능 시간 ↓ (반응 압박)

> 설계 원칙: **TTK 목표 구간을 잡소(잡몹)는 2.0~3.5초로 유지**한다. 적정 Lv 장비면 이 구간에 들고, *장비가 부족하면 TTK가 늘어 스택이 터진다.* 이것이 "장비로 파워를 통제"하는 메커니즘이다 — 어느 스테이지에서 얼마나 강할 수 있는지를 우리가 Lv 해금·가격으로 정확히 제어한다.

## 2. 스탯 & 등급 배율

### 2.1 스탯 5칸
| 스탯 | 의미 | 비고 |
|---|---|---|
| 원거리공격력 | 발당 원거리 피해 | 거리 압박 처리 |
| 근거리공격력 | 타당 근접 피해 | 코앞 적 처리 |
| 공격속도 | 초당 공격 횟수(배율) | DPS의 또 다른 축 |
| 체력 | 실패 게이지(방어력 통합) | 0 = 게임오버 |
| 이동속도 | 라인 위 이동 배율 | 직업 개성 |

### 2.2 등급(Lv) 배율 (직업 기본값에 곱함)
**Lv은 `원거리·근거리 공격력`과 `체력`만 배율로 키운다.** 공격속도·이동속도는 직업 고유값으로 Lv에 거의 불변(폭주 방지). Lv = "얼마나 세냐", 직업 = "어떻게 싸우냐". *(표시 이름: Lv1 이름없는 / Lv2 떠오르는 / Lv3 소문난 / Lv4 이름난 / Lv5 전설의)*

| Lv (표시명) | 배율 | 스킬 장착 슬롯 |
|---|---|---|
| Lv1 이름없는 | 1.0 | 2 |
| Lv2 떠오르는 | 1.5 | 2 |
| Lv3 소문난 | 2.2 | 3 |
| Lv4 이름난 | 3.2 | 3 |
| Lv5 전설의 | 4.5 | 4 |

> 슬롯은 "장착 가능 칸"이다. **스킬 자체는 동전으로 사서 채운다**(§2.4). 슬롯 < 보유 스킬이면 *골라 끼우는 선택*이 생긴다. 예: 1막 후반엔 보안관 스킬 3개 보유 + 슬롯 2개(Lv1·2) → 상황에 맞게 2개 선택.
> Lv업은 단순 수치 증가가 아니다. 슬롯이 늘고(Lv3에서 3번째 칸), Lv4·5 도달 시 직업 *시그니처 패시브*도 강해진다(예: 닌자 Lv5 "회피 시 분신 반격"). 이게 "Lv5 찍을 이유"를 만든다.

### 2.3 직업 스탯 예산 원칙
같은 Lv의 모든 직업은 *대략 비슷한 총 전투력 예산*을 갖되 **배분이 다르다**(사이드그레이드). Lv만이 순수 파워. 예: 같은 Lv1이라도 보안관은 근·원 균형, 메이드는 근접↑↑·원거리↓, 음악가는 원거리↑·체력↓.

### 2.4 스킬 = 구매·장착식 (★ 핵심 시스템)
스킬은 직업에 자동으로 딸려오지 않는다. **상점(맥스·라쿤)에서 동전으로 사서, 등급이 주는 슬롯에 골라 장착한다.**
- **직업 귀속:** "보안관 경고 사격"은 보안관 슬롯에만. 범용 금지(직업 정체성 + 밸런스를 직업 안으로 한정).
- **직업당 스킬 풀:** 1막 기준 직업당 3개. 1-9에 1번째, 1-15에 2번째, 1-17에 3번째 판매 개방.
- **3개 중 N개 선택:** 슬롯이 보유 스킬보다 적으므로(예: 3개 보유 / 2슬롯), *어떤 조합을 끼울지*가 전략. → **세 스킬은 역할이 겹치지 않게 설계해야 한다**(예: ①광역 청소 ②생존기 ③단일 폭딜 → 상황마다 정답이 다름). 셋이 비슷하면 선택이 무의미.
- **등급 ↔ 스킬 상호 보완:** Lv업(스탯↑)과 스킬 구매(능력↑)는 전투력을 채우는 두 축. 설계 목표 **`Lv1 + 좋은 스킬 ≈ Lv2 + 기본 스킬`**, *총 전투력과 총 비용이 엇비슷*하게. → 안정형(Lv 투자) vs 영리형(스킬 투자) 둘 다 유효.
- **강력 스킬 = 라쿤(가끔)·고가:** "Lv1로 막 깨려면 *꽤 좋은* 스킬이 필요"한 상황을 만들면, 라쿤이 파는 고가·희귀 스킬에 올인하는 *하이리스크 빌드*가 성립.
- **결제 불가, 동전 전용:** 스킬은 현금으로 못 산다. 무과금도 파밍하면 다 모음. (현금은 직업·코스튬·광고제거에만 — §5-B)

| 체력 | 120 (중) |
| 원거리공격력(접시) | 6 (약·보조) |
| 근거리공격력(빗자루) | 16 (강·주력) |
| 공격속도 | 1.0/s |
| 이동속도 | 1.15 |
| **크리율** | 15% (높음) |

- **평타:** 빗자루 = 근접 주력 + *약한 넉백*(살짝 밀림). 접시 = 원거리 보조(도망간 적·박쥐 마무리).
- **크리 효과:** **강넉백** — 적이 저 멀리 날아감(벽까지). 몰려올 때 크리로 한 무리 정리하는 쾌감. 크리율이 높아 자주 터짐.
- Lv별 근접 DPS: Lv1 16 / Lv2 24 / Lv3 35.2 / Lv4 51.2 / Lv5 72. 체력 120→600.
- **스킬 풀:**
  - **대청소** — 전방 광역 *강제 넉백* + 데미지, CD 12s. *역할: 평타 크리의 확정판, 스택 밀어내기.* (1-9, ~120)
  - **왁스칠** — 바닥에 미끄럼 장판(적 이동속도 대폭↓), CD 16s. *역할: 지연·제어.* (1-15, ~250)
  - **접시 폭풍** — 다수 접시 난사(원거리 광역), CD 30s. *역할: 보조 원거리를 한 방에 폭발.* (1-17, ~600 / 라쿤)

#### (3) 음악가 — 원거리 주력 (제어·디버프)
*저택 음악실. 음파로 멀리서 두들기고, 위기엔 적을 묶는다. 평타는 원거리가 셈.*
진급 호칭: 거리 악사 → 연주자 → 악장 → 명연주자 → 마에스트로 (→ 전설의 음악가)

**기본값(Lv1):**
| 스탯 | 값 |
|---|---|
| 체력 | 110 (간판 최저지만 몇 대는 버팀) |
| 원거리공격력(음파) | 14 (강·주력) |
| 근거리공격력(악기 타격) | 6 (약) |
| 공격속도 | 1.0/s |
| 이동속도 | 1.0 |
| **크리율** | 12% |

- **평타:** 음파 = 원거리 주력(셋 중 원거리 평타 최강). 악기 타격 = 근접 보조(붙으면 툭).
- **크리 효과:** **잠시 스턴**(0.7s) — 맞은 적 멈춤. 제어형 정체성을 크리로 표현.
- Lv별 원거리 DPS: Lv1 14 / Lv2 21 / Lv3 30.8 / Lv4 44.8 / Lv5 63. 체력 110→495(간판이라 물몸이어도 일정 생존선 유지).
- **스킬 풀:**
  - **불협화음** — 전방 광역 데미지 + 둔화, CD 10s. *역할: 원거리 광역 딜.* (1-9, ~120)
  - **자장가** — 범위 내 적 *스턴 장판*(잠깐 다 멈춤), CD 20s. *역할: 평타 크리의 확정판, 위기 제어.* (1-15, ~250)
  - **앵콜** — 자가 버프(공속·이동↑ 잠시), CD 30s. *역할: 물몸 보완·딜 폭발.* (1-17, ~600 / 라쿤)

> 세 직업 비교: **보안관**(근·원 균형, 크리=강타, 입문, 체력130) / **메이드**(근접↑·크리=강넉백, 몰린 적 컨트롤, 체력120) / **음악가**(원거리↑·크리=스턴·제어, 체력110로 간판 중 최저지만 *몇 대는 버팀*). 크리율도 메이드>음악가>보안관으로 달라 손맛 차이. 평타 크리(운) ↔ 스킬(확정)이 같은 효과의 약/강 버전이라 정체성이 일관됨. **※ 진짜 물몸(한두 대면 죽음)은 조연 닌자(체력70)의 몫 — 간판은 다 기본기가 튼튼하다.**

### 4.3 출시 라인업 (1막~3막)
- **맨몸 치즈**(Lv 고정) — 시작 기준선
- **간판 3종(Lv1~5 풀):** 보안관(균형·1-3 지급) / 메이드(근접) / 음악가(원거리·제어)
- 이 3종으로 *성장 시스템이 도는지* 검증. 고급 한정·시즌·프리미엄 직업은 출시 후.

### 4.3-B 2막부터 등장할 신규 직업 후보
2막(마당·야생: 뱀·까마귀·너구리)부터 *조연 직업*을 1~2종씩 추가. **간판과 카테고리·손맛이 겹치지 않게**, 배경(저택·시대) 적합 우선. 조연은 Lv 범위를 좁게(작업·밸런싱 절감), 고유 호칭은 생략하고 평판 라벨만.

**우선 후보 (배경 적합도·차별성 높음):**
| 직업 | Lv 범위 | 무게중심 | 크리 효과(개성) | 배경/출처 | 간판과 차별점 |
|---|---|---|---|---|---|
| **정원사** | Lv1~4 | 근접+설치 | 가시덤불 *속박*(적 멈춤) | 마당 도구. *2막 야생/뱀에 딱* | 메이드(넉백)와 달리 *묶어두는* 제어 |
| **요리사** | Lv2~4 | 근접 지속딜 | 화상 *폭발*(주변 추가딜) | 저택 주방 | 메이드(넉백)와 달리 *시간차 지속딜* |
| **사냥꾼** | Lv1~4 | 원거리 산탄 | 다중 명중 시 *즉사 확률* | 부자의 사냥 취미·벽 트로피 | 음악가(음파 단일선)와 달리 *근거리 광역 산탄* |
| **집사** | Lv2~4 | 근접 탱커 | *반격*(받은 피해 되돌림) | 저택 집사 정장 | 셋 중 없는 *순수 탱커* 역할 |
| **닌자**(밀수) | Lv2~4 | **초고속 원거리 난사** | 크리 시 *추가 표창 난사* | 2-1 라쿤(바다 건너온 물건) | 음악가(느린 묵직·제어)와 달리 *초고속 속사·제어 없음·극물몸*. 상세 §4.3-C |

**2막 추가 권장 = 정원사 + 닌자.** 정원사는 *제어(속박)*로 2막 야생 적과 잘 맞고 스토리 연결이 자연스럽고, 닌자는 *라쿤 첫 등장*(2-1)의 간판 상품이자 "강하지만 어려운" 빌드를 제공. 나머지(요리사·사냥꾼·집사)는 2막 후반~3막에 순차 추가 후보.

### 4.3-C 닌자 (조연 1호 · 2-1 오픈 · 라쿤 밀수)
*"바다 건너온 그림자." 초고속 표창 난사형. 극도로 약한 체력 → 한두 대면 죽음 → 고난도 컨트롤. 제어(스턴)는 없음 — 순수 화력 + 회피로 버틴다. "강하지만 어려운" 매운맛 직업.*
Lv 범위 **2·3·4 (하급·중급·상급)**. 진급 호칭 생략, 평판 라벨만(하급=떠오르는 등).

**기본값(Lv2, = 하급 닌자):**
| 스탯 | 값 |
|---|---|
| 체력 | **70 (극히 약함 — 한두 대면 위험)** |
| 원거리공격력(표창) | 8 (발당 낮음) |
| 근거리공격력(단검) | 7 (보조) |
| **공격속도** | **1.8/s (매우 빠름 — 핵심 정체성)** |
| 이동속도 | 1.6 (매우 빠름) |
| **크리율** | 18% (높음) |

- **평타:** 표창 = 초고속 원거리 난사(발당 약하나 빨라서 DPS는 높음 "약한 걸 많이"). 단검 = 근접 보조.
- 표창 DPS(Lv2): 8 × 1.8 = **14.4** — 음악가 Lv1(14)과 비슷하나 *훨씬 빠른 연사*라 체감·점사력 다름. Lv3 21.1 / Lv4 30.7. 체력 70→Lv4 약154(여전히 약함).
- **크리 효과:** **추가 표창 난사**(크리 시 표창 몇 발 추가 발사) — 화력형 정체성 강화. 크리율 높아 자주 폭발.
- **밀기:** 이동 1.6이라 대부분 적을 전진 중에도 밀 자격 되나, 붙으면 70체력이 *순식간에 증발* → 맨몸 밀기 사실상 불가. **무적 스킬(연막) 켜고 안전하게 밀고 → 왼쪽으로 빠지며 난사**가 핵심 생존 루프.
- **스킬 풀:**
  - **분신술** — 분신 1~2체 소환, 잠시 같이 난사(화력 폭발), CD 18s. *역할: 딜 폭발.* (2막 라쿤/상점, 고가)
  - **연막** — 짧은 무적(~1.5s) + 그 동안 안전하게 밀기/이동, CD 16s. *역할: 물몸 생존 핵심. 밀기와 결합.* *(제어 아님 — 적을 멈추는 게 아니라 본인이 안전해지는 것)*
  - **표창 폭풍** — 전방 대량 난사(광역), CD 25s. *역할: 군중 처리.*

> 닌자 vs 음악가(둘 다 원거리): **음악가** = 느린 묵직 음파 + 스턴 제어 + 체력110(누구나) / **닌자** = 초고속 표창 + 제어 없음 + 체력70(숙련자용·고화력). 같은 원거리지만 *속사 vs 제어*, *물몸 vs 기본기*로 정반대. 닌자는 Lv2부터라 "초반에 강한가?" 싶지만 *극물몸이 페널티* → 초보는 보안관, 숙련자는 닌자로 화력. (제어 수단이 없어 *오직 회피·연막·점프로* 버팀 = 컨트롤 난이도의 실체.)

> 조연 차별화 원칙: 간판이 *균형(보안관)·넉백근접(메이드)·원거리제어(음악가)*를 차지하므로, 조연은 그 *빈 칸*을 메움 — 속박제어(정원사)·지속딜(요리사)·근거리산탄(사냥꾼)·순수탱커(집사)·고기동회피(닌자). 크리 효과도 직업마다 달라 개성 유지.

### 4.4 직업 전체 풀 (로드맵용)
**1군 현실:** 맨몸 / 보안관 / 메이드 / 음악가 / 정원사 / 요리사 / 사냥꾼 / 집사 / 야구선수
**2군 노획·시대 세력:** 갱스터 / 경찰 / 발명가 / 탐정 / 전기공 / 광부 / 서커스 단원
**3군 황당(후반·라쿤 밀수):** 마술사 / 마법사(Lv4·5) / 닌자(밀수) / 사무라이(밀수) / 파라오(밀수) / 로봇 / 우주비행사 / 흡혈귀 / 슈퍼히어로 / 외계인(Lv5)
*(삭제: 비행사·우편배달부 — 탈것. 군인·권투선수·카우보이·소방관·재즈연주자 → 간판 교체·정리로 제외 또는 후순위)*

**Lv 범위 차등:** 기둥 직업 = 풀 라인(Lv1~5) / 끝판·진귀 = 고급 한정(Lv4·5) / 시즌·유료 = 단일 Lv. 유료 직업은 "더 셈"이 아니라 "다르게 놂 + 수집"(P2W 금지). 조연 직업은 풀 라인이 아니어도 됨(예: 정원사 Lv1~4, 닌자 Lv3·4).

## 5. 재화 시스템

### 5.1 단일 소프트 화폐 = 동전 (출시 기준 단순화)
**획득:**
- **적 처치:** 적별 코인(회색쥐·롤러쥐2 / 투척쥐·박쥐·참새3 / 벌·거미4 / 검은쥐류5~6). 막 올라갈수록 상향.
- **스테이지 첫 클리어 보너스:** `20 + 5 × (막 내 스테이지 번호)`. 예 1-1=25, 1-10=70, 1-19=115.
- **보스 추가 보너스:** 중간보스 +100, 최종보스 +200.
- **반복(파밍) 보상:** 클리어한 스테이지 재도전 시 *첫 클리어 보너스 없음*, 적 처치 코인은 정상 → 막히면 앞 스테이지 파밍 가능(선택적).

### 5-B. 수익 모델(BM) — 동전 판매 + 직접 판매 (P2W 금지)
- **동전 = 단일 화폐. 노가다(파밍)로 벌거나, 현금으로 구매.** 돈으로 사는 것은 *파워가 아니라 시간*. 무과금도 파밍하면 동일 도달.
- **현금 직접 판매 대상:**
  - **프리미엄 직업** — 성능은 무과금 최강과 *동급*, 차별점은 *독특한 플레이스타일 + 화려한 외형*("다르게 놂"). 예: 슈퍼히어로 치즈.
  - **코스튬** — 순수 외형(밸런스 무관).
  - **광고 제거** — 1회 결제.
- **"얻기 매우 어려운 직업" 만드는 법(P2W 없이):** ① 순수 유료 전용(성능 동급·특별함으로 소구), ② 극악 도전 보상(무과금도 가능하나 큰 노력 → 결제로 시간 단축), ③ 시즌·한정(희소성). 모두 *강함이 아니라 특별함·희소성*으로 욕구 유발.
- **절대 금지:** 현금으로만 얻는 *전용 파워*(더 강한 스킬·등급). 스킬·등급은 동전으로만.

### 5.3 1막 경제 sanity check
- 1막 총 수입(첫 클리어 기준) ≈ 처치 코인 ~450 + 클리어 보너스 ~1,080 + 보스 +300 ≈ **약 1,800 동전.**
- 예상 지출(권장 빌드): Lv1→2(150) + 스킬 1·2번째(120+250) + 2번째 직업(200) + 소모품(~150) ≈ **약 870.**
- 3번째 스킬(~600)·Lv2→3(400)·Lv2 직업(추가 비용)까지 *욕심내면 1막 수입으로는 빠듯* → 파밍하거나, 결제로 동전 보충하거나, D+스킬2개+실력으로 1-20 돌파. **세 갈래가 모두 유효한 빡빡함**이 의도.
- 결론: 돈이 의미 있되 막히지 않고, "더 갖고 싶다"가 파밍/결제/실력 중 하나로 해소됨.

### 5.4 소모품 휴대
전투 진입 시 소모품 슬롯 2~3칸. 회복·폭탄·츄르 + (3막부터) 함정 트랩(페인트통·다리미·구슬 등 고전 슬랩스틱)도 소모품으로 편입.

### 5.5 펄 — 출격 축복 + 호감도(로맨스) 시스템
펄은 **1-5 해금**. 스테이지 진입 *전*에 들러 그 판 한정 축복 1개를 고른다(매 판 무료 택1). 펄은 단순 버프 제공자가 아니라 *관계가 깊어지는 로맨스 서브플롯* — "치즈의 싸움에 반한 팬"에서 시작해 연인까지.

> **대원칙(필수화 금지):** 축복·호감도·로맨스는 *선택적 깊이*다. 안 올려도(보석 안 바쳐도) 기본 축복 3종 + 메인 진행에 지장 없음. 전투만 하고 싶은 유저도 완주 가능. 톤은 *카툰풍 가벼운 로맨스*(하트 뿅뿅·뽀뽀 쪽 수준, 전 연령 안전).

#### 기본 축복 3종 (1-5부터, 호감도 Lv1에서 3종 다 사용 가능 · 매 판 택1)
- **맹수의 발톱** — 그 판 공격력 +N% (딜)
- **튼튼한 배** — 그 판 체력 +N% (생존)
- **부자집 곳간** — 그 판 동전 획득 +N% (수급, 전투 무관 → 파밍용)

#### 호감도 = 보석 헌납 (게이지로 표시)
- 적 처치 드랍은 대부분 *소모품*(음식=회복, 폭탄 등 치즈가 씀). **가끔 보석류** 드랍.
- 보석은 **① 팔면 동전 / ② 펄에게 바치면 호감도↑** — 둘 중 선택(딜레마: 귀한 보석일수록 "팔까 바칠까" 고민↑).
- **보석마다 호감도 수치 차등**(예: 빛나는 조약돌 +1 / … / 다이아몬드 +100). 흔한 건 찔끔, 귀한 건 확. → 희소 드랍의 쾌감이 호감도로 직결.
- 호감도 **게이지를 눈에 보이게** 표시("다음 레벨까지 OO").
- **보석 구매:** 라쿤(가끔)이 *비싼 보석*을 동전으로 판매 → 호감도 빨리 올리고 싶은 사람용. (맥스는 안 팖 — 희소성 유지. P2W 아님: 동전으로 사고 축복은 필수 아님.)

#### 호감도 레벨 1~5 (축복 강화 + 컷신 + 호칭)
레벨 오르면 ① **축복 3종 동시 강화**(Lv1→Lv5에서 정확히 2배), ② **썸 타는 컷신**(눈빛 변화→뽀뽀 쪽), ③ **호칭·대사 톤 변화**.

| Lv | 호칭(한/영) | 발톱·튼튼한배 | 곳간(동전) | 컷신/해금 |
|---|---|---|---|---|
| 1 | 치즈 선생님(존댓말) / Sir Cheese | +15% | +25% | 기본 3종 사용 (팬·동경) |
| 2 | 치즈 씨(존댓말) / Mr. Cheese | +18% | +30% | 눈빛 변화 |
| 3 | 치즈 오빠(존댓말) / Cheese | +22% | +35% | **새 축복 해금**(크리율) · 오빠라 부르지만 아직 조심 |
| 4 | 치즈 오빠(반말) / Cheese~ | +26% | +40% | 뽀뽀 컷신 · 말투 풀림·애정 |
| 5 | 자기야(허니) / Honey | +30% | +50% | **새 축복 해금**(펄의 가호) + **연인 → 데이트 미니게임 해금** |

- **증가폭 균등**(매 레벨 +3~4%p), 만렙 = 처음의 2배. 동전만 25→50%로 후하게(전투 밸런스 무관).
- **호칭 사다리 = 팬→연인 한 방향, 3번의 분기가 각각 다름:** Lv2→3 호칭 친밀화(씨→오빠), Lv3→4 *말투 존댓말→반말 전환*(최대 체감), Lv4→5 연인 호칭. 호칭은 *상시 체감·저비용*(텍스트만), 컷신은 *순간 보상·고비용*(그림).

#### 새 축복 2종 (호감도로 해금)
- **Lv3 해금 — 행운의 표창** : 그 판 크리율 +10%. (직업 크리 효과를 더 자주 터뜨림)
- **Lv5 해금 — 펄의 가호** : 그 판 공격·체력·이동 +10%씩 + 부활 1회(죽어도 1회 체력 회복하며 부활). 연인 펄의 최강 종합 축복. *단 없어도 클리어 가능 선 유지.*

#### 1막 범위
보석이 희소 드랍이라 1막 안엔 **호감도 Lv2~3 정도**가 현실적. 1막의 펄 = 기본 3종(15→22%) + Lv3 크리율 축복 맛보기 + 눈빛 변화 컷신. **Lv4 뽀뽀·Lv5 펄의가호·연인·데이트는 2막 이후 장기 목표.** *보석 드랍·헌납·동전화는 1막부터 작동.*
- **데이트 미니게임 = 출시(3막)에도 미포함, 라이브 콘텐츠로 후속 추가.** 설계엔 "최고 호감도 = 데이트 해금"이라는 *틀*만 박아둠(별도 미니게임 제작은 게임 성공 후).

### 5.5-B 호루라기 (동료 호출) — 1막 2종
거리에서 사귄 친구를 *호루라기로 불러* 전투를 돕는 시스템. **동료 호출 슬롯 1개**에 장착 → *매 판 택1*. 쿨타임 기반 액티브.

**획득 구조 (만남=정서 / 호루라기=비용):**
- **만남 = 공짜 이벤트.** 거리에서 친구가 되는 짧은 컷(그림 한두 장+대사). → "산 용병"이 아니라 *사귄 친구* (길고양이 치즈의 정체성과 직결).
- **호루라기 = 맥스 상점 구매(동전, ~200~300).** 친구가 됐어도 *부르는 도구는 사야* 함. 둘 다 사귀어도 *호루라기는 각각 구매* → "어느 걸 먼저 살까" 우선순위 선택. (공짜 아님 + 경제 사용처)
- **장착:** 산 것 중 슬롯 1개에 매 판 택1.

**1막 2종 (둘 다 딜보다 *유틸* — 어느 직업과도 어울리고, 특히 원거리 딜러와 시너지):**

| 동료 | 타입 | 효과 | 역할 | 쿨타임(안) | 만남 |
|---|---|---|---|---|---|
| **치와와** | 넉백·유틸(지상) | 좌→우로 컁컁 달리며 *막힌 지상 적을 전부 오른쪽 끝까지 밀어냄.* 데미지 거의 없음. **밀기 규칙 무시**(빠른 적·물량도 다 밂). **단 지상 전용 — 몸집이 작아 공중의 박쥐는 못 밂** | *공간·시간 리셋* — 코앞 지상 적 밀어내고 다시 거리 확보 (공중은 비둘기 담당) | ~30s (강력해서 길게) | 1-13 (비 오는 골목, 떠는 치와와에게 밥 한 입 → 컁!) |
| **비둘기** | 둔화·광역(공중) | 날아와 *똥 폭격*, 맞은 적 *둔화*(끈적임). 공중(박쥐)에도 명중 | *전체 둔화* — 느려진 적 밀기·사격 쉬워짐, 박쥐 대응 | ~22s | 1-16 (다친 비둘기 돌봐줌 → 푸드덕 은혜 갚으러) |

- **치와와 = 원거리 딜러의 짝꿍.** 음악가·닌자가 코앞에 몰렸을 때 치와와로 적을 밀어내고 → 다시 거리 두고 난사. **닌자는 무적(연막)을 아끼며 거리 확보** 가능(치와와가 대신 밀어줌).
- **비둘기 둔화 vs 음악가 스턴:** 비둘기는 *둔화*(느려짐), 음악가 크리는 *스턴*(정지) → 제어의 결이 달라 안 겹침.
- **치와와 첫 만남(1-13) = 동료 시스템 튜토리얼:** 호루라기가 뭐고, 슬롯 장착·전투 중 호출법을 이때 설명. 비둘기(1-16)부턴 만남+구매 안내만 가볍게.
- **확장:** 황소 등 *큰 체급* 동료는 후반 막(큰 적 등장 시)을 위해 보류 → "치와와 → … → 황소" 스케일업. 추가 동료도 *만남 이벤트(무료) + 맥스 호루라기 판매(유료)* 패턴 반복.

### 5.6 플레이 타임 목표
- **일반 스테이지 1~2분 / 보스 2~4분.** 모바일 틈새 플레이에 맞고(5분 넘으면 시작 부담↑), 보스는 절정이라 길되 4분 초과 시 재도전 부담↑.
- §1의 잡몹 TTK 2~3.5초·보스 HP(1막 1000/1900)가 이 시간대 기준으로 검산됨.
- **콘텐츠 고갈 대응 = 시간↑가 아니라 "다시 할 이유"↑:** 빌드 실험(스킬 조합)·파밍·점수/속도 도전·다른 직업 재도전. 한 판은 짧고 밀도 있게.

**검산 메모:**
- 잡몹 TTK 목표 2~3.5초(§1.3) 기준으로 마릿수·M을 미세조정. **새 적 10종 + 새 M배율(1.0~2.2)로 잡몹 TTK 재검산 예정.**
- 1-10 보스 / 보안관 Lv1 + 경고 사격 → 구두차가 *멈춰 헐떡일 때* 평타·스킬 집중, 돌진·낙하는 점프/이동 회피. 스킬 1개가 *체감되는* 첫 벽.
- 1-20 / 보안관 Lv2(원거리 18.2dps) → 뱀 1900HP ≈ 90초대. *머리 박혀 멈출 때* 집중 딜, 물기·꼬리·내리꽂기는 회피. **Lv1(12.1dps)로도 가능**(스킬 2개+회피 실력) → "Lv1 돌파" 빌드 성립.

> **등급은 강제 아님 재확인:** 위 "권장"은 *편한* 선. 1막 전체가 Lv1 + 잘 고른 스킬 2개 + 회피 숙련으로 클리어 가능하도록 설계. Lv2는 동전을 Lv에 투자한 사람에게 주는 *난이도 완화*이지 관문이 아니다.

## 7-B. 이동·카이팅·밀기 (단일 화면 안에서)
**전투 공간은 화면 한 폭 고정**(§1.1). 치즈는 항상 오른쪽(적 쪽)을 본 채, *좁은 구간*에서 좌우로만 움직인다. 이동은 두 가지:
- **전진(오른쪽)** = 적 쪽으로. **앞 적을 몸으로 밂**(적 정지 중이면 누구나 / 전진 중이면 이동속도>적, 막힌 적 3마리 이하일 때). 붙으면 맞음.
- **후퇴(왼쪽)** = 적 쪽을 *계속 보면서* 뒤로 물러나며 사격 = **카이팅.** 단 *집(왼쪽 끝)이 한계*라 멀리 못 감 → "멀리 도망"이 아니라 *화면 내 미세 간격 조절.*

후퇴는 전진의 좌우 반전이 아니다(반전하면 적에게 등을 돌림). **별도 모션 필수.**

**좁은 공간의 함의:** 카이팅·밀기 모두 *큰 이동이 아니라 정밀한 위치 싸움*이다. 그래서 닌자처럼 "빠지는" 생존이 *공간 이동(순간이동)*이 아니라 *무적 시간(연막)* 으로 구현됨(§4.3-C). 멀리 못 빠지니, 코앞 위기는 점프(회피)·연막(무적)·밀기로 푼다.

**밸런스 주의 (튜닝 시):** 카이팅/밀기가 너무 강하면 점프·근접이 무의미해진다. 제어 수단:
1. 후퇴 이동속도 < 전진 이동속도 (뒷걸음은 느리게)
2. 집(왼쪽 끝)이 후퇴 한계 — *이미 존재*
3. 고속 적(바퀴 1.7)은 카이팅으로 못 떼고 밀기도 안 됨(거의 안 멈춤) → 사격·점프 강제
4. 밀기는 막힌 적 3마리 넘으면 불가(물량은 몸으로 못 뚫음) → 사격으로 수 줄이기 강제

## 7-C. 에셋 & 애니메이션 사양 (스프라이트 제작 기준)

### 핵심 원칙
- **게임 로직이 보는 것은 "프레임 수"가 아니라 "재생 시간(초)"다.** 직업마다 프레임 수가 달라도, 같은 모션의 *재생 시간*과 *판정 타이밍*만 맞추면 게임은 동일하게 작동한다. → **프레임 수는 통일하지 않는다. 타이밍을 통일한다.**
- **등급(Lv1~5)은 모션 재활용.** 직업당 모션 한 벌만 제작, 등급 차이는 색·이펙트·장식으로. (S에서 열리는 새 스킬만 신규 모션)
- **연출 모션(승리·좌절·공용 사망)은 전 직업 공용** — 맨몸 치즈 기준 1회 제작, 28직업이 공유.
- 작업자가 그래픽 디자이너이므로 AI 생성분 보정 가능 → 프레임을 *권장* 선까지 늘려도 됨. 단 모션 중요도에 따라 차등.
- **이펙트는 본체에서 분리.** 총구 화염·칼 잔상·폭발은 별도 레이어로 얹어 본체 프레임 절약 + 화려함 확보.
- **피격은 프레임 대신 흰색 틴트 깜빡임(코드 처리)으로 대체 가능** → 거의 공짜.

### 모션별 사양 (재생 시간 = 표준 / 프레임 = 권장)
| 모션 | 표준 재생시간 | 권장 프레임 | 루프 | 판정/비고 |

### 직업당 작업량 추정
- **직업마다 신규:** 아이들·걷기·뒷걸음·점프·원거리·근접·피격·사망 + 스킬(1~3) = **약 8~11종 모션.**
- **권장 프레임 기준 직업당 핵심 모션 합계 ≈ 50프레임 안팎** (스킬 수에 따라 증감).
- **공용(전 직업 1회):** 승리·좌절·(선택)공용 사망.
- **표준 리그:** 맨몸 치즈를 먼저 완성해 *프레임 수·타이밍·길이의 표준*을 확정 → 보안관·메이드·음악가는 그 위에 무기·스킬·크리효과만 교체해 가속.

## 8. 제작 시작 순서 (MVP → 점증, = 온보딩 순서와 동일)

1. **세로 슬라이스 (비공개):** 단일 스테이지, 맨몸 치즈, 쥐만. 이동·사격·근접·점프·HP·승패 판정. → *"재밌나"부터 검증.*
2. **웨이브 시스템:** 스폰 간격·웨이브 산 곡선.
3. **직업/장착:** 보안관 추가 + 장착(교체) 화면. (1-3 지급 흐름)
4. **상점 + 코인:** 맥스, 코인 획득/소비, 등급업.
5. **적 확장:** 회색 3종(쥐·롤러·투척) → 공중 4종(박쥐·참새·벌·거미) → 검은 3종(2티어).
6. **스킬 시스템:** 쿨타임 액티브(경고 사격 등) + Lv별 슬롯 2~4 + 구매·장착.
7. **소모품:** 폭탄·회복·츄르.
8. **보스:** 1-10 펑거스(구두차)·1-20 뱀 — 화면 휘젓기 패턴 + 2페이즈.
9. **콘텐츠:** 1-1 ~ 1-20 전체 배치 + 난이도 곡선 적용.
10. **메타 루프:** 게임오버→재도전, 파밍, 세이브/로드, 설정.

> 1~3번이 핵심. 여기서 "재미 + 내 개발 속도"가 확인되면 4번 이후를 자신 있게 찍어낸다.
