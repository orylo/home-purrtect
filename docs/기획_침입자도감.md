# Home Purrtect — 침입자 도감 (정리 문서)
> **이 문서의 역할**: 침입자(적) 카드의 포맷·UX 라이팅 요령·공통 규칙을 박아두고, 그 위에 침입자별 카드를 채워 가는 도감 원본. 포켓몬 도감처럼 모아 보는 수집 화면을 목표로 한다. 기획 챗(claude.ai)에서 정리.
> **공식 명칭**: 게임 안팎에서 적을 **「침입자」**로 부른다. (도감 화면 이름도 "침입자 도감".)
> **연결**: 수치·행동 원본은 `기획_시스템밸런스_1막.md` §3, 전리품·드랍은 `기획_아이템도감.md`. 자매 문서 = `기획_직업도감.md`(포맷·UX 철칙 공유).
> **갱신 주체**: 기획 챗이 원본을 채우고, Code가 게임에 반영하며 `STATUS.md`에 현황 표시.
> **상태**: 1막 침입자 10종(들쥐 6 + 날짐승·벌레 4)의 게임 내 노출 확정. 변종 2종(말벌·독거미)·보스 2종(펑거스·큰 뱀)은 다음 단계.

## 0. 도감의 두 영역
침입자 카드도 직업 도감과 같이 두 영역으로 관리한다.
- **■ 게임 내 노출** — 플레이어가 침입자 도감 화면에서 읽는 글. 아래 UX 라이팅 요령(§1)을 반드시 따른다.
- **■ 내부용** — 개발·기획용 메모(비노출). 티어·수치·드랍률·대응법·아트 노트.

## 1. UX 라이팅 요령 (게임 내 노출 = 반드시 준수)
자매 문서 `기획_직업도감.md` §1의 철칙을 그대로 따르며, 침입자에 특화된 항목을 더한다.

**직업 도감과 공유하는 원칙**
1. 정보 위계를 줄바꿈으로 가른다. 이름 / 분류 / 정체성 / 설명을 각각 다른 줄·블록으로. 한 줄에 여러 정보를 욱여넣지 않는다.
2. 정체성(한 줄) ≠ 설명, 역할을 가른다. 정체성 = 무슨 생물인지(세계관·성격). 설명 = 어떻게 움직이고 공격하는지.
3. 항목은 `라벨 : 값` 한 줄로. 공격·드랍 등은 라벨을 붙여 또렷이.
4. 블록 사이에는 빈 줄을 넣는다. 공격 / 드랍이 서로 붙지 않게 한 줄 띄운다.
5. 줄임말·전문용어는 풀어쓴다. 유저가 바로 이해하는 말로.
6. 군더더기를 뺀다. 굳이 없어도 되는 정보는 자른다.
7. 노출 최소주의. 게임 내 노출엔 읽는 재미와 감 잡기에 필요한 것만. 정확한 수치(HP·DMG)·드랍률·티어 표기는 내부용으로 내린다.

**침입자에 특화된 요령**
8. 수치 대신 "감"으로. 체력·공격력 숫자는 노출하지 않는다("맷집이 약하다 / 한 수 위다" 정도의 정성 표현으로). 난이도 모드(M배율)에 따라 수치가 바뀌므로, 노출하면 오히려 헷갈린다.
9. 대응법은 설명에 녹인다(별도 라벨 X). "밀어내기 딱 좋다 / 총으로 처리한다 / 피해야 한다"처럼 설명문 안에 자연스럽게 흘린다. 별도 "대응" 항목은 두지 않는다.
10. 주어를 분명히 — 누가 하는 행동인지 헷갈리지 않게. "돌은 좌우로 피한다"(누가?) → "좌우로 움직여 피해야 한다"(플레이어가). 침입자가 피하는 것처럼 읽히면 안 된다.
11. 공격 표기는 짧은 서술체 + 거리 구분. `근접 — ~한다` / `원거리 — ~한다`. 상태이상이 있으면 끝에 `· 독`, `· 둔화`로 덧붙인다.
12. 장점이 아니라 "위협의 결"을 보여준다. 직업은 장점 중심으로 쓰지만, 침입자는 어떤 식으로 성가신지(빠름·물량·원거리·독 등)를 캐릭터답게 드러낸다. 단, 무섭기보다 귀엽고 능청맞은 1930년대 카툰 톤.

## 2. 카드 포맷
### ■ 게임 내 노출 (이 순서·이 형식 고정)
```
## (이름)
(분류 — 예: 들쥐 · 지상)        ← 직업 도감의 '등급 라벨' 자리

(정체성 한 줄 — 무슨 생물인지, 세계관)

(설명 — 어떻게 움직이고 공격하나, 대응법 녹여서, 카툰 톤 2~3문장)

**공격** : 근접/원거리 — ~한다 (· 독/둔화)

**드랍** : (전리품)
```
### ■ 내부용 (비노출 메모)
```
- 분류 / 티어 : (들쥐·날짐승·벌레 / 회색1군·검은2군 / 지상·공중)
- 등장 : (첫 등장 스테이지)
- 스탯 : HP / 방어 / DMG / 공격간격 / 이동 / 코인
- 걷·멈 리듬 : (걷 Ns / 멈 Ns — 밀 기회)
- 밀기 : 가능 / 불가
- 대응 : (밀기·회피·사격 중 무엇)
- 패밀리 : (회색↔검은 강화판 관계 등)
- 드랍률 : (전리품 % / 보석 2% 별도)
- 아트 노트 : (생김새·뷰)
```

## 3. 공통 규칙 (전 침입자 적용)
- 카드 단위 = 종류별 별개. 회색쥐와 검은쥐(강화판)는 서로 다른 도감 항목(수집 칸이 늘어 모으는 맛↑). 변종(말벌·독거미)도 별개 항목.
- 회색 = 1군 / 검은 = 2군 강화판. 같은 수법·색만 검고 셈. 검은 계열은 설명에서 "회색보다 한 수 위"라는 차별점만 짧게.
- 수치의 단일 진실원천(SSOT) = 코드(`enemy_data.gd`). 내부용 스탯은 코드 기준으로 갱신.
- 공중 침입자(날짐승)는 몸으로 못 민다. 점프해 닿거나 멀리서 쏴서 상대.
- 상태이상: 벌 = 독(지속뎀), 거미 = 둔화(이동·공격 느려짐). 도감 설명·공격 라벨에 반영.
