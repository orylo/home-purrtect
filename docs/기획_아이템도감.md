# 기획_아이템 도감 (에셋 기반 역카탈로그)

> **이 문서의 성격**: 나노바나나로 뽑은 **아이템 아이콘 에셋 90종**을 *역으로* 정리한 카탈로그.
> "그림이 이미 있으니 → 기획에 편입"하는 방향. 기존 시스템밸런스 §5.2(전리품)·§5.4(소모품)와 매핑하고, 나머지는 **신규 후보로 제안**(채택·수치는 기획 챗이 결정).
> **에셋 경로**: `assets/items/{food,gadgets,loot}/<이름>.png` (전부 투명 PNG, 누끼 완료).
> **범례**: ✅ = 기존 코드(`game_state.gd`)에 이미 있는 ID에 그림이 생김 / 🆕 = 신규 제안(미구현) / 💰 = 재화·연출용(전리품 아님).
> **원본 백업**: 누끼만 한 전체 257컷은 `~/Downloads/items/cut/`. 미사용 변형(사르딘 캔·드럼스틱·사탕·양동이·소금통 등)도 거기 있음.
> **★확정 출처(SSOT 문구·수치):** 채택 아이템의 인벤토리 설명·수치는 **도감 5종**(`기획_직업도감`·`기획_침입자도감`·`기획_전리품보석도감`·`기획_소모품도감`·`기획_장난감도감`)이 정답. **이 파일 = 에셋↔ID 매핑 + 미채택 후보 카탈로그.** 충돌 시 도감·코드(`game_state.gd`) 우선.
