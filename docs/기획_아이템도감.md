# 기획_아이템 도감 (에셋 기반 역카탈로그)

> **이 문서의 성격**: 나노바나나로 뽑은 **아이템 아이콘 에셋 73종**을 *역으로* 정리한 카탈로그.
> "그림이 이미 있으니 → 기획에 편입"하는 방향. 기존 시스템밸런스 §5.2(전리품/재료)·§5.4(소모품)와 매핑하고, 나머지는 **신규 후보로 제안**(채택·수치는 기획 챗이 결정).
> **에셋 경로**: `assets/items/{food,gadgets,loot}/<이름>.png` (전부 투명 PNG, 누끼 완료).
> **범례**: ✅ = 기존 코드(`game_state.gd`)에 이미 있는 ID에 그림이 생김 / 🆕 = 신규 제안(미구현) / 💰 = 재화·연출용(재료 아님).
> **원본 백업**: 누끼만 한 전체 257컷은 `~/Downloads/items/cut/`. 미사용 변형(사르딘 캔·드럼스틱·사탕·양동이·소금통 등)도 거기 있음.
