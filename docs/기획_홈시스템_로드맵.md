# Home Purrtect — 홈 & 시스템 구현 로드맵

> **이 문서의 역할:** 전투 뼈대(코어전투·직업4종·적10종·보스 placeholder·웨이브) 위에, 그 전투를 감싸는 **메타 루프**(홈에서 출발 → 세팅 → 출격 → 보상 → 다시 홈)와 그에 얽힌 시스템(코인·상점·스킬·펄·동료)을 *어떤 순서로* 올릴지 정리한 로드맵.
> **갱신 주체:** 기획 챗이 단계별 상세를 채우고, Code가 구현하며 STATUS.md에 현황 반영.
> **상세 수치·규칙은 `기획_브리프.md`(§7-B 화면구조 / §6 캐릭터)·`기획_시스템밸런스_1막.md`(§5 재화·§5.5 펄·§5.5-B 호루라기·§2.4 스킬)에 이미 있음 — 여기선 “순서와 범위”만 정의.**

## 0. 왜 이 순서인가 (의존성)

핵심 원리: **아래가 위를 떠받친다. 순서를 뒤집으면 “쓸 데 없는 코인”이나 “갈 데 없는 홈”이 생긴다.**

```
6. 펄 · 동료 (정서 레이어)        ← 시스템이 다 선 뒤
5. 스킬 시스템 (전투 코드까지 손댐)  ← 상점·성장 위에
4. 상점(맥스) + 성장(레벨업·직업구매) ← 코인을 "쓰는" 곳
3. 전투 준비 화면 (직업/장착 세팅)    ← 홈에서 갈라지는 첫 분기
2. 홈 화면 (허브)                  ← 모든 화면이 모이고 갈라지는 중심
1. 코인 경제 (재화)                ← 모든 시스템의 바닥
─────────────────────────────────
   [완성된 전투 뼈대]               ← 현재 위치 (STATUS 0.21)
```

- **코인이 바닥인 이유:** 상점·레벨업·펄 보석·동료 호루라기가 전부 코인을 쓴다. 코인 없이 상점부터 만들면 살 돈이 없다.
- **홈이 그다음인 이유:** 상점·펄·전투준비·출격이 전부 “홈에서 갈라져 나가는 가지”. 홈이라는 허브가 있어야 각 시스템이 *붙을 자리*가 생긴다.
- **펄·동료가 마지막인 이유:** 보석 드랍→헌납, 호루라기 구매 등은 코인·상점·드랍 시스템이 다 선 뒤라야 자연스럽다. 정서 레이어라 급하지 않다.

## 1단계 — 코인 경제 (바닥 깔기)

**목표:** 코인이 *모이는 것*부터. 아직 쓸 데는 없어도 된다.

- 적 처치 시 코인 획득 (적별 코인값 — 시스템밸런스 §3.1 표의 “코인” 칸: 회색쥐·롤러쥐 2 / 투척쥐·박쥐·참새 3 / 벌·거미 4 / 검은쥐류 5~6).
- 스테이지 첫 클리어 보너스 `20 + 5 × (막 내 스테이지 번호)` (§5.1). 보스 보너스(중간 +100 / 최종 +200).
- **반복(파밍) 시 첫 클리어 보너스 없음**, 처치 코인은 정상.
- 상단 HUD에 코인 표시(💰 + 숫자).
- 세이브(save.json)에 coins 저장·로드. (GameState에 coins 필드는 이미 있음 — 채우기만)
- **이 단계 끝:** 전투하면 코인이 쌓이고, 새로고침해도 유지된다. 쓸 곳은 아직 없음.

> 범위 주의: 여기선 “획득·표시·저장”만. 쓰는 건 4단계.

## 2단계 — 홈 화면 (허브)

**목표:** “시작 → (홈) → 출격 → 전투 → 결과 → 홈” 루프의 중심을 만든다. 지금은 시작화면에서 바로 직업선택·전투로 가는데, 그 사이에 **홈**을 끼운다.

- 새 씬 `home.tscn` — 저택 배경(임시 도형/단색 OK) + 모서리 UI (브리프 §7-B 홈 레이아웃 참고).
- 레이아웃(혼합형): 상단 바 = 💰 코인 + 현재 막 표시 + ⚙ 설정 / 좌하단 = [전투 준비] / 우하단 = [출격 ▶](크게) + [맵](작게).
- **이 단계에선 빈 버튼이라도 자리만:** 상점·펄 진입점은 자리만 잡아두고 “준비중”으로(3·4·6단계에서 연결).
- [출격] = 현재 진행 스테이지로 바로 전투. [전투 준비] = 3단계 화면으로.
- 플레이어 모드 흐름: 시작 → [게임 시작] → **홈** → [출격] → 전투 → 클리어 → **홈으로 복귀**(다음 스테이지가 현재 진행으로 갱신된 채).
- 개발자 모드는 기존대로(개발자 메뉴 → 바로 전투) 유지 — 홈 안 거침.

> **결정 필요:** 클리어 후 곧장 다음 스테이지로 갈지, 홈을 거칠지. 브리프 §7-B는 “이벤트 없으면 [다음 ▶] 바로 / 있으면 컷신 후” — 즉 *기본은 연속, 홈은 선택*. 1단계 구현에선 일단 “클리어 → 결과 패널 → [다음 ▶](바로 다음 전투) + [홈으로](작게)“로 두면 충분.

## 2-B. 전투 결과 화면 & 게임오버 화면

### 결과 화면 (클리어) — 두 갈래
전투 클리어 시 결과 화면을 띄운다. 이벤트 유무로 흐름이 갈린다.

**A. 일반 클리어 (이벤트 없음):**
- 💰 획득 코인을 크게 강조 (처치 + 클리어 보너스 합산).
- 일반 전리품은 한 줄로 간단히 나열("회색쥐 털 ×4, 롤러 바퀴 ×1" / 인벤토리에 추가됨).
- 💎 보석은 나왔을 때만 따로 강조 줄(희소 쾌감).
- [다음 스테이지 ▶] [홈으로] 둘 다 자유 선택. 다음=바로 다음 전투 / 홈=홈 복귀(세팅·상점·파밍).

**B. 해금 이벤트 있는 클리어 (1-3, 1-5, 1-7 등) — 진행 막고 확인 강제:**
- 보상(코인·전리품)은 똑같이 표시하되, 진행 버튼 대신 [확인 ▶] 하나만 둔다. ([다음]·[홈] 없음)
- [확인]을 누르면 → 이벤트 실행 → 이벤트가 끝나야 그제야 [다음 스테이지 ▶] [홈으로]가 열린다.
- 핵심: 이벤트 스테이지는 진행을 막고 [확인]만 둬서 반드시 이벤트를 거치게 한다(해금을 놓치지 않게).
- 이벤트 스테이지 (시스템밸런스 §6-A): 1-3 보안관 지급 / 1-5 펄 해금 / 1-7 상점 오픈(+메이드·음악가 제작 가능) / 1-9 스킬 판매 / 1-13 비둘기 / 1-15 둘째 스킬 / 1-16 치와와 / 1-19 Lv2 직업 / 1-10·1-20 보스 클리어(막 연출). (3번째 스킬·Lv3 슬롯은 2막 라쿤)
- 지금 구현 범위: 이벤트 내용(컷신·NPC)은 아직 미구현 → 당장은 "[확인] → 간단한 안내 텍스트(예: '보안관을 얻었다!') → 진행 버튼 열림"으로 구조만 잡는다. 나중에 각 이벤트를 그 자리에 끼움. 중요한 건 "이벤트 스테이지는 막고 확인 강제" 구조를 지금 박아두는 것.

### 게임오버 화면 (실패) — 자리만
- 치즈 HP 0 → 게임오버. 연출(쫓겨남 코미디·영감 전보)은 미구현, 지금은 자리만.
- [재도전] = 방금 실패한 그 스테이지 재시작 (보유 자산·코인·전리품 전부 유지 — 브리프 §7 강제 리셋 없음).
- [홈으로] = 홈 복귀(파밍·세팅 후 재도전).
- 연출은 콘텐츠 단계에서 추가. 지금은 버튼 2개 구조만.

> 결과·게임오버 둘 다 구조(보상 표시 / 이벤트 게이팅 / 진행 선택지)가 핵심. 연출·이벤트 내용은 나중에 각 자리에 끼운다.

## 3단계 — 전투 준비 화면 (직업/장착 세팅)

**목표:** 임시 직업선택을 정식 “전투 준비”로. 핵심 = "마지막 세팅을 기억했다가 그대로 재사용, 바꾸고 싶을 때만 변경".

### 핵심 원칙 — 마지막 세팅 기억 + 선택적 변경
- 플레이어가 마지막 출격한 세팅(직업·Lv·장착 소모품 등)을 세이브에 저장.
- 홈에서 [출격] → 그 세팅 그대로 바로 전투. (안 바꿀 거면 전투 준비 안 들러도 됨)
- 바꾸고 싶을 때만 [전투 준비]에 들러 변경 → 변경분이 다시 "마지막 세팅"으로 저장.
- → 매판 다시 고르는 귀찮음 없이, 원할 때만 바꾸는 흐름.

### 4개 탭 (브리프 §7-B 구조)
**① 직업 탭 (3단계에서 진짜로 작동):**
- 보유(해금)한 직업 목록에서 택1. 선택된 직업 강조 + 직업명·등급 라벨·현재 Lv 표시.
- 잠긴 직업은 흐리게 + 해금 조건 표시(예: "1-7 상점에서 제작").
- 직업 해금 타임라인(1-3 보안관 / 1-7 메이드·음악가 제작)은 이미 구현됨 → 그 상태를 읽어 표시.

**② 소모품 탭 / ③ 스킬 탭 / ④ 동료 탭 = 3단계엔 자리만("준비중" placeholder):**
- 소모품 = 4단계(상점·실제효과)에서 작동. 스킬 = 5단계. 동료 = 6단계.

### 저장되는 "마지막 세팅"
- 선택 직업 + 각 직업 Lv (job_level — 이미 있음).
- 장착 소모품 = "종류 슬롯"만 저장 (어느 슬롯에 회복/폭탄/츄르를 배치할지). 실제 들고 가는 개수는 보유 재고만큼 자동 채움. 소모품은 1회용이라 전투에서 쓰면 재고 감소 → 슬롯 배치는 유지, 양은 재고 따라감.
- (나중) 장착 스킬 / 동료.

### 3단계 범위 (이번에 만들 것)
- 직업 탭 진짜 작동 + 마지막 세팅 저장/로드 + 홈[출격]이 저장된 세팅으로 바로 진입.
- 나머지 3탭은 자리만. 소모품 슬롯 UI는 두되 실제 장착·사용은 4단계에서 연결.
- 개발자 모드는 영향 없음(개발자 메뉴에서 자유 설정 유지).

## 4단계 — 상점(맥스) + 성장 (코인을 쓰는 곳)

**목표:** 드디어 코인을 쓴다. “코인 모아 강해지는” 핵심 루프가 처음 돈다.

- 맥스 상점 씬(홈에서 진입). 캐릭터·대사는 나중, *기능부터*.
- **판매 항목 (시스템밸런스 §5.2 가격표):**
  - 직업: 메이드·음악가 = 재료+코인500 제작(시스템밸런스 §5.2-B). 보안관 = 1-3 자동 지급.
  - 직업 레벨업: Lv1→2 = 1,000 / 2→3 = 2,500 / 3→4 = 5,000 / 4→5 = 10,000 (§5.2-C).
  - 소모품: 낡은 붕대 40 / 말린 멸치 50 / 폭죽 80 (§5.4) (구매·보유 — 실제 전투 사용은 별도, 아래 참조).
- 레벨업 구매 → job_level 갱신 → 전투에서 Lv 배율 적용(이미 작동). 세이브 저장.
- **이 단계 끝:** 전투로 번 코인으로 레벨업/직업을 사서 더 세짐. 게임의 성장 루프 완성.

> **확정:** ① 직업 해금 = 상점 재료 제작으로 확정(§5.2-B). 보안관만 1-3 자동 지급, 메이드·음악가는 1-7 상점 오픈 후 재료+코인500 제작. ② **남은 결정:** 소모품 “보유”와 “전투 중 사용(하단 슬롯)“을 이 단계에 같이 넣을지, 사용은 뒤로 뺄지.

## 5단계 — 스킬 시스템

**목표:** 직업별 스킬을 사서 슬롯에 끼우고 전투 중 발동. *전투 코드까지 건드리는 큰 작업이라 성장 루프가 선 뒤에.*

- 스킬 데이터: 직업당 3개 (시스템밸런스 §4.2 각 직업 “스킬 풀” — 보안관 경고사격/방패자세/지원요청 등 전부 정의돼 있음).
- Lv별 슬롯 수 2-2-3-3-4 (§2.2). 슬롯 < 보유 스킬이면 “어느 걸 끼울까” 선택.
- 상점에서 스킬 구매(§5.2-C: 250 / 500 / 1,000). 1막은 1·2번째(1-9, 1-15)까지, 3번째는 Lv3 슬롯=2막 라쿤(§4.2·§5.2-C). 스킬도 Lv 배율 받음.
- 전투 준비 [스킬] 탭에서 장착. 전투 중 하단 우측 스킬 버튼(쿨타임) — HUD 자리는 이미 있음(placeholder).
- 쿨타임·발동·효과(광역딜·넉백·스턴장판·버프 등) 구현.
- **이 단계 끝:** 직업 × 스킬 조합으로 빌드가 생긴다. 1막 후반 난이도의 해법.

> 범위가 크니 세부는 이 단계 들어갈 때 별도로 쪼갬(데이터 → 장착UI → 전투발동 순).

-----

## 6단계 — 펄(축복) + 동료(호루라기)

**목표:** 정서 레이어 + 출격 전 선택지. 시스템이 다 선 뒤 얹는다.

- **펄(§5.5):** 1-5 해금. 출격 전 축복 1개 택1(맹수의 발톱=공격 / 튼튼한 배=체력 / 부자집 곳간=동전). 보석 드랍 → 팔기(코인) or 헌납(호감도). 호감도 레벨·게이지·호칭 변화. *1막은 Lv2~3까지가 현실적.*
- **동료(§5.5-B):** 비둘기(1-13, 공중 둔화)·치와와(1-16, 지상 밀기). 만남 이벤트(무료) + 호루라기 맥스 구매(유료). 전투 준비 [동료] 탭 장착 + 전투 중 호출 버튼(쿨타임).
- **이 단계 끝:** 출격 전 축복 선택 + 동료 호출까지 — 1막 시스템 풀세트.

## 범위 밖 (이 로드맵 이후 / 나중)

- 보스 패턴(돌진·장판·2페이즈) — 지금 placeholder, 전투 폴리시 단계에서 따로.
