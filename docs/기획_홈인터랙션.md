## 0. 왜 만드는가 (설계 의도)

이 게임은 **싱글플레이·단일 히어로·스토리 완결형**이라, 경쟁/무한성장/소셜압박 같은 고수익 F2P 엔진이 없다.
→ 이 게임에서 유저를 붙잡고 (보너스) 수익을 만드는 동력은 **파워가 아니라 "치즈에 대한 애착"**이다.

홈 인터랙션 = **애착 엔진의 심장.**
- 유저가 "내 치즈"를 보고 쓰다듬으며 정이 든다 → 재방문(리텐션)
- 정든 치즈를 **예쁘게 입히고 싶다** → 코스튬 구매 동기 (BM 핵심)
- 정든 치즈를 **응원하고 싶다** → 후원 팁("츄르 사주기") 동기
- 즉 **인터랙션을 잘 만들수록 코스튬·팁이 팔린다.** 돈 생각 없이 재밌게 만들어도 수익 기반이 깔리는 구조.

또한 단일 히어로이기에 *오히려* 가능한 설계 — 캐릭터가 하나라서 깊게 팔 수 있다.

## 1. 핵심 설계 원칙 (중요 — 흔한 함정 회피)

1. **반응 "가짓수"가 아니라 "살아있다는 느낌"이 핵심.**
   적은 반응이라도 *예측 못 할 때* 생명감이 산다. 똑같은 반응 = 3번 만에 질림. 랜덤 = "얘 뭐지?" 하고 또 켬.
2. **세 엔진: ① 랜덤성 ② 시간/상태 변화 ③ 누적 보상.** 이게 다마고치의 진짜 동력. 기능 추가보다 이 세 개를 먼저.
3. **당근만, 채찍 없음.** 돌보면 좋은 일(O) / 안 돌보면 벌(X). 방치 페널티는 게임을 *끄게* 만든다.
4. **관리 부담 최소화.** 배고픔·청결·행복 게이지 3종 동시 관리(옛날 다마고치) = 숙제. → **단일 "기분" 상태 하나로 통합.**
5. **작게 시작 → 반응 보고 확장.** 처음부터 크게 만들면 본편(5막)을 못 끝낸다.

## 2. 단일 상태 모델 — "기분(Mood)"

게이지 여러 개를 두지 않는다. **치즈의 상태 = "기분" 하나**로 표현(내부 수치, UI엔 게이지바 노출 안 함 — 표정/연출로만).

- 기분은 **밥·놀이·교감(쓰다듬기)** 세 행동으로 오른다.
- 기분은 시간이 지나면 **천천히** 내려간다(아주 완만하게).
- 기분이 낮으면 = **시무룩** (눈 처짐, 꼬리 축, 느린 반응). 그 이상은 없음.
- **시무룩의 규칙(엄수):**
  - 돌아와서 **쓰다듬기 한 번이면 즉시 회복**.
  - **실질 페널티 0** — 전투 스탯·진행·보상에 일절 영향 없음. 순수 연출.
  - **아프거나 떠나지 않음.** "오래 안 봤네?" 정도의 가벼운 신호일 뿐, 처벌이 아니다.
  - 죄책감 유발 금지. (예: "치즈가 굶고 있어요!" 같은 푸시 알림 ❌)

> 기분이 좋을 때 = 골골·활발·특별반응 확률↑. 즉 *돌보면 더 귀엽게 논다*는 당근.

## 3. 세 가지 교감 행동 (밥·놀이·교감 루프)

홈 화면의 치즈/주변 오브젝트를 탭해 상호작용. 셋 다 기분을 올리지만 결이 다름.

### ① 교감 (쓰다듬기) — 가장 기본, 가장 자주
- 홈에서 **치즈를 탭** → 랜덤 반응.
- **반응 풀 (랜덤, 4~6종):** 골골거리며 눈 감기(💗) / 기지개 / 앞발 핥기(그루밍) / 갸웃하며 쳐다보기(❓) / 부비적 / (저확률 특별) 데구르르 구르기·나비 쫓기.
- **같은 자리 연타해도 매번 다른 게 나오게** — 생명감의 80%가 여기서 나옴.
- 코드 가벼움: 애니 클립 몇 개 + 가중 랜덤 선택.

### ② 밥 (밥그릇)
- 홈의 **밥그릇 탭** → 밥 주기. 치즈가 다가와 먹음(먹는 애니 + 만족 💗).
- 밥그릇이 비어 있으면 살짝 표시(배고픈 티) → 채우면 좋아함.
- 밥은 **무료·무제한이 아니라 가벼운 리듬**: 하루 1~2회 주는 정도(쿨타임). 너무 자주 = 의미 퇴색.

### ③ 놀이 (장난감/깃털)
- **장난감 오브젝트 탭** → 치즈가 쫓고 점프하고 잡는 짧은 놀이 모션.
- 가장 "활발한" 연출 → 기분 크게 상승. 볼거리(코스튬 자랑에도 좋음).
- 1일 1회 정도의 특별 상호작용으로.

> **확장 여지(출시 후):** 새 장난감/간식 종류, 계절 오브젝트(눈 굴리기 등). 행동 종류는 늘리되 *관리 게이지는 안 늘림*.

## 4. 누적/데일리 보상 — "로그인 보상의 정서적 포장"

"출석체크 하세요"(사무적) 대신 "치즈가 반겨요"(애착)로 포장.

### 데일리: 오늘 첫 교감 보상
- 하루 첫 쓰다듬기(또는 첫 밥) 시 보상 1회.
- **보상 = 랜덤:** 동전 소량 / 츄르 1개 (둘 다 풀에 넣고 랜덤).
- **가끔(저확률) 특별 드랍:** 치즈가 "선물을 물어옴" — 작은 보석/추가 동전. → *변동 보상*("오늘은 뭐 줄까?")으로 기대감.
- 이게 사실상 데일리 리텐션 장치인데, 캐릭터 연출로 자연스럽게 위장.

### 누적: 친밀도 (출시 후 우선)
- 교감 횟수 누적 → 내부 친밀도 단계.
- 단계 오르면: 특별 반응 해금 / 가끔 치즈가 선물 물어옴 / 작은 연출 변화.
- **주의:** 친밀도를 *유료로 사게 하지 말 것.* 교감(=플레이)으로만 오름. (BM은 코스튬·팁으로, 애정 자체를 팔지 않음 — §6 참조)

## 5. 펄 연동 (애착 엔진 확장)

브리프 §6: 펄은 호감도 오르면 "창가→마당→곁"으로 거리를 좁힘. → **홈 인터랙션 장에 펄도 등장.** (상세 `기획_펄로맨스.md` §11)

- 치즈를 쓰다듬으면 **펄이 (호감도 위치에서) 지켜보고 반응** — 새침하게 시선 휙(꼬리 살랑) / 💗 / 커튼 뒤에서 훔쳐봄.
- 호감도 낮음 = 옆집 창가에서 멀리 / 높음 = 마당·곁에서 가까이 반응.
- **홈 인터랙션 장 하나가 동시에 떠받치는 것:**
  - 치즈 애착(교감)
  - 펄 로맨스(거리 좁히기 연출)
  - 코스튬 무대(입힌 치즈를 보고 감상)
- 펄 콘텐츠(호감도·컷신)는 **전부 무료.** 펄로 생긴 애착이 *코스튬·팁으로* 흐르게 함. 펄 자체를 과금 대상으로 삼지 않음(결이 나빠지고 리뷰 갈림).

## 6. BM 연결 요약 (왜 이게 수익 기반인가)

| 인터랙션 요소 | 연결되는 수익원 | 메커니즘 |
|---|---|---|
| 치즈를 보고 쓰다듬는 무대 | **시즌 코스튬** | "내 치즈 예쁘게 입히고 싶다" |
| 치즈에 대한 정 | **후원 팁("츄르 사주기")** | "이 캐릭터 응원하고 싶다" |
| 데일리 첫 교감 보상 | 리텐션 | 재방문 → 광고 노출·구매 기회↑ |

- **애정 자체는 절대 팔지 않음** (호감도·친밀도 유료화 ❌). 애정은 무료로 키우고, 그 위에 외형(코스튬)·응원(팁)을 얹는다.
- 인터랙션 품질 ↑ = 애착 ↑ = 코스튬·팁 구매 동기 ↑. **재미와 수익이 같은 방향.** (BM 상세 `기획_브리프.md` §10)
