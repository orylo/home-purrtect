# Home Purrtect — 이벤트 연출 가이드
> **이 문서의 역할**: 게임 내 모든 **이벤트 연출(컷씬·팝업·인게임 이벤트)의 공통 규칙·용어·작성법**을 정의하는 체계 문서. *"어떻게 만드는가."*
> **짝 문서**: 실제 스테이지별 대사·비트는 `기획_이벤트대본_1막.md`(막마다 분리). *"무엇을 말하는가."*
> 이 문서는 잘 안 바뀜(규칙). 대본 문서는 자주 채워지고 바뀜.
> **연결**: 톤·캐릭터 = `기획_브리프.md` §6·§6-B / 서사 곡선 = `기획_세계관_치즈서사.md` / 구현 현황 = `STATUS.md`(스테이지 이벤트 시스템 `stage_intro.gd`).

## 0. 세 가지 연출 타입 (용어 — 반드시 이 셋으로만 부른다)
| 타입 | 정의 | 화면 | 조작 | STATUS 코드 대응 |
|---|---|---|---|---|
| **인게임 이벤트** | 전투 화면 **안에서** 캐릭터 스프라이트가 움직이고 대화창이 뜨는 연출. NPC가 걸어 들어오고/나감. | 전투 씬 그대로 | 잠금(연출 중) | `stage_intro` "인트로" |
| **팝업** | 전투 화면 **위에** 딤(어둡게) + 대화창만. 스프라이트 연출 없음, 대사만. | 전투 위 오버레이 | 잠금(일시정지) | `stage_intro` "팝업" |
| **컷씬** | 전투 **밖**, 화면을 완전히 덮는 전용 이미지/연출. 독립 장면. | 풀스크린 | 없음 | `prologue.tscn` 류 |
**핵심 구분:**
- **인게임 이벤트 ↔ 팝업**: 둘 다 전투 중. 차이는 "스프라이트가 움직이느냐(이벤트) / 대화창만 뜨느냐(팝업)".
- **컷씬**: 전투 밖 풀스크린. 가장 무거운 연출이라 아껴 씀.
- ⚠️ "전투 내 컷씬" 같은 혼용 표현 **금지**. 전투 안이면 인게임 이벤트나 팝업이지 컷씬이 아니다.
**컷씬은 전투무관 서사도 포함한다.** 전투에 딸린 연출(해금·획득)뿐 아니라 **스테이지와 무관한 순수 스토리 장면**도 전부 컷씬 타입이다:
- **프롤로그**(게임 시작 시 1회 — 비 오는 거리 → 골드에게 거둬짐)
- **막 전환**(막과 막 사이 — 신문 헤드라인 몽타주)
- **엔딩**(5막 종결)
- **게임오버**(영감 전보)
→ 이런 비-스테이지 컷씬도 이 체계로 관리하며, 대본 문서 안에 해당 막의 **도입(프롤로그)·마무리(막 전환)** 섹션으로 둔다(가이드 §5·대본 문서 구조 참조).
**언제 무엇을 쓰나 (기본 가이드):**
- 등장/퇴장처럼 **동선이 있으면** → 인게임 이벤트
- 짧게 끼어드는 **한두 줄 대사** → 팝업
- **장면이 바뀌는 큰 사건**(획득·변신·막 전환·회상) → 컷씬
- 인게임 이벤트 → 컷씬으로 **자연 전환** 가능(예: 치즈가 오브젝트로 걸어가 → 카메라 줌인 → 컷씬). 단절감 없애는 권장 기법.

## 1. 이벤트 트리거 (Code 훅 지점)
이벤트는 아래 시점에 건다. 한 스테이지에 여러 개가 붙을 수 있다.
| 트리거 | 시점 | 주로 쓰는 타입 |
|---|---|---|
| `전투 시작 전` | 웨이브1 스폰 직전 | 인게임 이벤트(NPC 등장) |
| `첫 몹 처치` | 그 스테이지 첫 적 죽을 때 (**1회만**) | 팝업 |
| `N웨이브 시작` | 특정 웨이브 스폰 시점(새 적 등장 등) | 팝업 |
| `날씨 전환` | 날씨 프리셋이 바뀌는 시점(§3) | 무대사 연출 / (선택) 팝업 |
| `전 웨이브 클리어` | 마지막 적 처치 직후 | 인게임 이벤트(NPC 퇴장) |
| `해금/획득` | 클리어 후 보상·해금 시 | 인게임 이벤트 → 컷씬 |
| `게임오버` | 치즈 HP 0 | 컷씬(영감 전보) |
- **1회성 플래그**: 대부분 1회만 재생하고 `seen` 저장(재도전 시 자동 스킵). 게임오버 컷씬만 반복.
- **해금 게이팅**(홈 로드맵 §2-B): 해금 이벤트가 있는 스테이지는 클리어 후 [확인]만 띄워 **반드시 이벤트를 거치게** 한다(해금 놓침 방지).

## 2. 치즈 연출 제약 (★ 반드시 지킬 것)
> **적용 범위**: 이 7종 제약은 **인게임 이벤트·팝업**에만 적용된다(전투 화면 안에서 실제 게임 스프라이트가 보일 때). **컷씬(풀스크린)은 예외** — 별도 일러스트/연출이라 7종에 안 묶이며, 표정·동작을 자유롭게 그릴 수 있다(단 치즈 무대사 원칙은 컷씬에서도 유지).
치즈는 **전 구간 무대사.** 인게임 이벤트·팝업에서는 표정·몸짓 전용 스프라이트가 따로 없으므로, 치즈 반응을 **보유 스프라이트 + 머리 위 기호**의 조합으로만 짠다.
### 보유 스프라이트 = 직업당 7종 (이것 외에는 없다)
`아이들링` / `근접공격` / `원거리공격` / `걷기` / `점프` / `피격(피해입기)` / `엎드리기`
### 연출에 쓸 때 규칙
- **무관심/의문** → `아이들링` + 머리 위 `❓` (강조하려면 물음표 크게)
- **여유/도발** → `근접공격` 또는 `원거리공격` 모션 1회 + `✨` (무기 슥 휘둘러 보이기)
- **이동** → `걷기` (등장·퇴장·오브젝트로 다가가기)
  - **컷씬·인게임 이벤트에서는 걷기 스프라이트 좌우 flip 허용** (전투 중 "왼쪽으로 못 걷는다" 규칙은 연출엔 적용 안 됨). 치즈가 목표보다 오른쪽이면 flip해 왼쪽으로 이동.
- **신남/까불기** → `점프` (가볍게 통통, 필요 시)
- ⚠️ **`엎드리기`는 연출용 금지** — 직업별로 모양이 다르고(방어 포즈 vs 자는 포즈), 특히 길냥이는 **방어 포즈**라 "딴청·무관심"이 아니라 "쫄았다"로 읽힘.
- ⚠️ **`피격`은 감정 연출용 금지** — "맞았다"로 오해됨. 데미지 연출에만.
- ⚠️ "콧구멍 후비기·어깨 으쓱·고개 갸웃" 같은 **전용 동작은 없다.** 쓰지 말 것(스프라이트 추가 비용).
### 머리 위 기호 (자유 — 이펙트 레이어, 스프라이트 무관)
`❓` 의문 · `❗` 놀람 · `💗` 호감 · `💢` 분노 · `💡` 아이디어 · `✨` 여유/감탄 · `💦` 진땀
- 기호는 스프라이트 위에 얹는 거라 자유롭게 쓴다(치즈 감정 표현의 주력).

## 3. 날씨 연출 (활용 가능 — STATUS 0.51 `weather.gd`)
날씨는 **연출 자산**이다. 스테이지 분위기 + 긴장 곡선 + 서사 모티프에 쓴다.
### 사용 가능한 것 (STATUS 기준)
- **단일 분위기**: 쾌청 / 노을 / 밤 / 흐림(overcast)
- **입자**: 비 / 눈 / 낙엽 / 먼지
- **빛**: 반딧불 / 번개(천둥 선행 → 섬광)
- **복합 전환**:
  - `transition` = 밤+비 → 여명 → 아침
  - `shower` = **흐림+비 → (특정 웨이브 진입 시) 비 그치고 해** ← 스포너의 웨이브 신호 구독
- **게임 기본 = 날씨 없음.** 연출 의도가 있는 스테이지에만 지정(예: 1-3 = shower).
### 서사 모티프 (세계관 §통일모티프)
**비 = 취약·상실 / 햇빛·온기 = 소속.** 날씨 전환을 감정 곡선에 맞추면 대사 없이도 의미가 실린다.
- 예) 1-3: 비 맞으며 마지막 고비 → 해 뜨며 돌파 → 직후 첫 장비(보안관) 획득 = "비→온기"의 작은 운율.
### 작성 규칙
- 대본에 **날씨 시작값 + 전환 시점**을 명시한다. 예: `날씨: shower (시작 흐림+비 / 3웨이브 진입 시 해)`.
- 날씨 전환은 **무대사 연출만으로도 충분**(긴장 환기). 필요 시 팝업 1줄로 캐릭터가 반응하게 할 수도 있음(선택).

## 4. 펑거스 — 말투 규칙 (라이벌 겸 튜토리얼 빌런)
> 펑거스는 1막의 핵심 라이벌. **1-1~1-9는 직접 안 싸우고 떠들기만 하는 겁쟁이**(졸개만 풀고 화면 오른쪽으로 퇴장). **1-10에 처음 기계 타고 직접 등장.** 새 적/시스템이 처음 나오는 스테이지에만 등장해 약 올리며 *결과적으로* 튜토리얼을 한다.
### 말투 3대 버릇 (다국어 번역에 안전한 것만)
1. **3인칭 거창 자칭** — "이 몸 펑거스가", "위대한 펑거스님" (허세). *영어: "the great Fungus" / 일어: 「このファンガス様が」 — 코믹 빌런 클리셰라 번역 살아남음.*
2. **거창한 단어 ↔ 쩨쩨한 실제의 낙차** — "나의 위대한 군단!" 외치는데 나오는 건 회색쥐 세 마리. 말과 실제의 갭이 개그.
3. **빡칠 때 끓어오름** — "끄으윽—!", "너… 너 이놈—!" (한 서린 순간 + 코믹).
- ⚠️ **말끝 버릇("찍" 등) 금지** — 한국어에서만 작동, 번역에서 죽음. + 마스코트 톤이라 5막 비극·화해 곡선과 충돌.
- **퇴장 = 항상 화면 오른쪽 바깥으로 달려가 사라짐.** 펑거스는 횡스크롤 공식("적은 오른쪽")에서 *유일하게 오른쪽으로도 가는 적*. 침입자이자 도망자라는 정체가 동선으로 드러남.
- **정체 숨김 연출**(첫 등장): 대화창 이름표 `?` + 얼굴 실루엣 → 정체 밝히는 대사에서 `?` → `펑거스`로 전환.
### 비대칭 거울 (대사 톤의 핵심)
펑거스는 그날을 평생 기억하고 한을 품지만, **치즈는 까먹었다.** 펑거스가 열올릴수록 치즈는 `❓`. *가해자는 잊고 피해자만 기억하는* 이 비대칭이 코미디이자 후반 비극의 씨앗(세계관 사다리 B).

## 5. 작성 포맷 (대본 문서가 따를 양식)
**대본 문서(`기획_이벤트대본_N막.md`) 구조** — 한 막 파일이 그 막의 도입~마무리를 자족적으로 담는다:
1. **막 도입 컷씬** — 막 맨 앞. *(1막 파일 한정: 게임 전체 1회성 **프롤로그**를 맨 위에 둠 — "1막"이 아니라 게임 오프닝이지만 1막 도입으로 묶어 관리.)*
2. **스테이지 이벤트** — 1-1, 1-3 … 순서대로.
3. **막 전환 컷씬** — 막 맨 끝(다음 막 예고 / 신문 몽타주).
각 스테이지 이벤트는 아래 형식으로 쓴다.
```
# 1-N — 부제 (새 요소 / 보상)
> 무대 / 치즈 상태(직업) / 날씨 / 새 요소 / 웨이브 구성(§6-B 참조)
### ① [트리거] — [타입]
(연출 지문 — 동선·카메라)
> 화자 : "대사"
(치즈: 스프라이트 + 기호)
→ 다음 동작(전투 시작 / 퇴장 / 전환 등)
```
- **타입은 §0 셋 중 하나로 명시**(인게임 이벤트 / 팝업 / 컷씬).
- **치즈 반응은 §2 제약 안에서만**(7종 + 기호).
- **날씨 지정 시 §3 형식**으로.
- 펑거스 대사는 §4 말투 규칙 준수.
- 화자 이름표: 정체 숨길 땐 `?`, 공개 후 실명.

## 6. 트리거별 튜토리얼 매핑 (1막 — 시스템을 대사로 가르치기)
새 시스템/적은 **설명충 UI 대신 펑거스 대사로** 자연 전달한다. (1막 기준 예시)
| 스테이지 | 새 요소 | 펑거스가 깔아주는 것 |
|---|---|---|
| 1-1 | 첫 전투 | 막아서기(디펜스 룰) / 전투 / 웨이브 / 후속 스테이지 |
| 1-3 | 투척쥐(원거리) | "멀리서 던진다" → 다가오기 전 사격으로 솎기 |
| (이후) | 롤러쥐·박쥐·검은쥐·거미·벌 등 | 각 적의 대응법을 약 올리듯 예고 (대본에서 작성) |
> 1-1에서 이미 가르친 것(웨이브 등)은 이후 반복 설명 안 함. 펑거스 등장은 **새 요소 있는 스테이지에만**(조작이 쉬워 매 판 등장은 불필요).
