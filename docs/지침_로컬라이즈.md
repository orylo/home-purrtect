# 지침 — 로컬라이즈(언어분기) 선행준비

> **주인=나(Claude Code).** "언젠가 언어분기" 대비해 **배관만 미리 깔아둔** 상태. 실제 600여 문구 전수 이관은 1막 완성 후 단계적으로.
> 핵심: **지금 동작은 한국어 그대로**(로케일 `ko` 고정). 새 텍스트만 아래 규칙대로 넣으면 나중이 편함.

## 1. 지금 깔려있는 것 (v0.0.144~)
- **번역 테이블**: `assets/i18n/ui.csv` (`keys,ko,en` 형식). CSV 저장하면 Godot이 `ui.ko.translation`·`ui.en.translation` 자동 생성.
- **등록**: `project.godot [internationalization] locale/translations=[...ui.en.translation, ...ui.ko.translation]`, `locale/fallback="ko"`.
- **로케일 고정**: `GameState._ready` → `TranslationServer.set_locale(language)` (`language="ko"`). 영어기기에서도 안 튐.
- **전환 훅**: `GameState.set_language("en")` 호출 시 즉시 전 `tr()` 텍스트가 영어로(화면 재진입 권장).
- **레퍼런스 구현**: `scripts/start.gd` — 버튼 텍스트를 `tr("ui.start.play")` 식으로 전환(작동 증명·복붙 패턴).

## 2. 새 텍스트 넣는 법 (지금부터 이렇게)
```gdscript
# 인라인 한글 대신:
btn.text = tr("ui.shop.buy")           # 키로 호출
```
그리고 `assets/i18n/ui.csv`에 한 줄 추가:
```
ui.shop.buy,구매,Buy
```
→ Godot 에디터가 자동 재임포트(헤드리스면 `Godot --headless --import .`).

### 키 네이밍 규칙 `영역.화면.용도`
- `ui.<screen>.<what>` — 화면 UI. 예: `ui.start.play`, `ui.shop.buy`, `ui.hud.pause`, `ui.common.no`(공용).
- `enemy.<id>.name` / `enemy.<id>.desc` — 침입자 도감.
- `item.<id>.name` / `item.<id>.desc` — 전리품·보석·소모품·장난감.
- `job.<id>.name` — 직업.
- `cut.<who>.<n>` — 컷씬 대사(예: `cut.pearl.1`). `sys.<key>` — 시스템 알림.

## 3. 관습 (어기면 나중에 번역 깨짐)
1. **문장 이어붙이기 금지.** `"펄의 호감도가 " + n + " 올랐다"` ❌ → 템플릿: `tr("sys.fav_up") % n` (`sys.fav_up = "펄의 호감도가 %d 올랐다"`). 어순이 다른 언어에서 조립식은 깨짐.
2. **텍스트는 데이터 테이블에.** 컷씬/적/아이템은 이미 딕셔너리(`game.gd CUT_*`, `enemy_data.gd`, `game_state.gd`)에 모임 — 유지. UI 라벨도 가능하면 한 곳.
3. **숫자·기호만인 것은 번역 대상 아님**(버전 "0.0.x ver.", 별 ★ 등).

## 4. 텍스트 지도 (어디에 뭐가 있나 — 이관 시 순서 참고)
| 영역 | 위치 | 분량 | 이관 난이도 |
|---|---|---|---|
| 화면 UI 라벨/버튼 | start·select·home·shop·hud·stagemap·dev_menu .gd (인라인) | 多 | 흩어짐(중간) |
| 컷씬 대사 | `game.gd` `CUT_PEARL/MAX/SHERIFF/DOVE/CHIHUAHUA/GAMEOVER` | 中 | 데이터(쉬움) |
| 인트로 이벤트 | `stage_intro.gd` `EVENTS` | 中 | 데이터(쉬움) |
| 적·아이템·직업 이름/설명 | `enemy_data.gd`·`game_state.gd` 딕셔너리 + 도감 문서(원천) | 多 | 데이터(쉬움) |
| 시스템 알림 | game.gd sys 페이지·event.gd | 小 | 쉬움 |
| 프롤로그 자막 | `prologue.gd` `BEATS[].cap` | 小 | 데이터(쉬움) |

> 총 한글 문자열 리터럴 ≈ 600개(30개 .gd). 도감 5종(기획 문서)이 **이름·문구의 원천** → 이관 시 도감↔CSV 매핑으로 정합성 유지.

## 5. 실제 언어분기 할 때(미래) 순서
1. CSV 컬럼에 목표 언어 추가(`en`/`ja`…) + 번역 채움.
2. 데이터형(컷씬·적·아이템·자막)부터 키화 → 흩어진 UI 라벨 → 나머지.
3. 설정 화면에 언어 선택 → `GameState.set_language(code)` + 세이브 필드(`language`) 연결.
4. **폰트 글리프 확인**: 일어/중문 추가 시 Pretendard·타이틀폰트가 해당 글자 커버하는지(`FontFile.has_char`).
5. 줄바꿈/길이: 영어가 더 길어 버튼 넘침 → 레이아웃 가변폭 점검.

## 6. 주의(웹/CSV 함정)
- CSV 셀에 **줄바꿈(`\n`)**: Godot은 `\n` 문자열을 그대로 출력(이스케이프 해석 안 함). 줄바꿈 필요하면 키를 줄별로 쪼개 코드에서 `+"\n"+`, 또는 따옴표 안 실제 개행. (그래서 현재 시드 CSV는 단문만.)
- `export_filter="all_resources"`라 `.translation`은 빌드에 자동 포함됨(별도 설정 불필요).
