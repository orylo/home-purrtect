# Home Purrtect (홈 퍼르텍트) — 게임 기획 브리프

> 떠돌이였다 부자 노인에게 거둬진 고양이 '치즈'가, 주인이 여행 떠난 저택을 홀로 지키는 횡스크롤 액션 디펜스. 1930년대 카툰(러버호스/컵헤드) 톤. *제목 = Home(집) + Purr(고양이 골골) + (pro)tect(지키다) 말장난.*
> *(이 문서는 상위 기획 스냅샷입니다. 전투 수치·밸런스·스테이지 난이도 등 제작용 상세는 짝 문서 〈시스템 & 밸런스 설계서 — 1막〉에 있습니다. 미정 항목은 맨 아래 12번 참조.)*

## 1. 한 줄 요약

1930년대 러버호스 카툰풍(컵헤드/플라이셔)의 **횡스크롤 액션 디펜스**. 주인공 고양이 **치즈**가 살아있는 방어선이 되어, 오른쪽에서 밀려오는 침입자(쥐 → … → 외계인)로부터 집을 지킨다. **iOS 우선 · 가로 모드 · 단일 히어로 · 직업 세트 기반 성장.**

> **제목 = Home Purrtect (홈 퍼르텍트).** Home(집) + Purr(고양이 골골) + (pro)tect(지키다)의 말장난 → *고양이가 집을 지킨다*는 게임 본질을 한 번에 전달. "Home"이 맥락을 줘서 purrtect를 protect로 자연히 읽게 함. **한국·해외 통일 제목**(발음 쉬움). 로고에선 **Purr**를 강조 표기.
> - *제목 결정 경위:* 〈나 홀로 집에〉 패러디("냥홀로집에/Home-ow Alone")는 — Home Alone이 디즈니(구 폭스)의 *살아있는 등록 상표*이고 *게임 카테고리에도 진출*한 IP라, 같은 분야 유사 제목은 혼동 가능성·경고장·소송 리스크가 있어 **폐기.** (2023 잭다니엘스 판결 후 제목의 패러디 보호도 좁아짐. Ion Maiden·Goldmember 등 제목 분쟁 선례 존재.) 대신 *독창적 말장난* Home Purrtect로 리스크 회피 + 고유 정체성 확보. **게임 내 3막의 도둑 코미디 오마주(슬랩스틱 함정)는 톤 차원에서 유지** — 제목으로 베끼지 않을 뿐.
> - **⚠️ 출시 전 필수:** Home Purrtect의 상표 클리어런스 검색(앱스토어·USPTO·KIPRIS 등) + 가능하면 IP 변호사 상담 후 *직접 상표 등록* 권장. (독창적이라 안전 가능성 높으나 확인은 필수.)

## 2. 세계관 & 정서

게임을 꿰는 두 개의 척추가 있다.

- **감정의 엔진 — "쫓겨나면 갈 곳이 없다".** 치즈는 원래 비 오는 거리의 길고양이였고, 외롭고 부유한 노인 **골드 영감**이 거둬 처음으로 "집"을 줬다. 그래서 치즈에게 해고는 단순 실직이 아니라 *다시 길바닥, 가족 상실*이다. 모든 코미디 밑에 이 절박함이 깔린다.
- **논리의 엔진 — "소문이 전설이 된다".** 저택 깊은 금고에 전설의 보물이 있다는 소문이 돈다. 치즈가 침입자를 물리칠수록 신문·라디오·입소문으로 명성이 커지고, 그 소문을 들은 *더 크고 더 미친* 세력이 차례로 몰려온다. 치즈가 강해지는 것 = 적이 강해지는 것 = 전설이 커지는 것이 한 흐름이다.

**라이벌 — 생쥐 "펑거스(Fungus)".** *치즈와 운명이 뒤바뀐 거울상.* 원래 **골드의 집에 살던** 쥐로, 고양이가 오기 전까진 영감의 음식을 털어먹으며 평온하고 호화로운 나날을 보냈다. 그런데 골드가 길거리의 치즈를 주워온 *바로 그날*, 치즈가 영감에게 잘 보이려고 이 쥐를 잡아 엉덩이를 뻥 차서 집 밖으로 쫓아냈다. 그 한 번의 사건이 둘의 운명을 갈랐다 — *치즈는 신임을 얻어 가족이 되었고, 펑거스는 길바닥으로 추락*했다. 이후 벽 속에서 곰팡이처럼 썩어가며(이름의 유래), 어떻게든 **그 안온한 집으로 돌아가겠다**는 일념으로 매 막 *자기보다 센 세력*을 끌어들인다(쥐떼 → 야생동물 → 인간 도둑 → 호랑이 → 외계인). 이 모든 점증하는 침공의 근원이 사실 *쫓겨난 쥐 한 마리의 귀향 집념*이었다는 게 핵심. (와일드 E. 코요테 포지션 + 도덕적 입체성: 치즈가 *먼저* 걷어찼기에 펑거스도 마냥 악당은 아니다.)

**이름 궁합:** 곰팡이(Fungus)는 *치즈에 피는* 것 → "치즈 vs 펑거스" = 주인공을 갉아먹으려는 라이벌이라는 은유. 치즈(소박한 출신→거물 "the big cheese")와 펑거스(풍족했던 과거→썩은 현재)가 *이름으로도 서사로도* 대비.

**최종 반전.** 모두가 노린 "전설의 보물"의 정체는 골드 영감의 **유언장 겸 입양 서류** — 치즈를 유일한 상속자이자 정식 가족으로 명시한 문서. 보물은 처음부터 *치즈 자신*이었다. 영감이 귀환하고, 내내 전보로 날아오던 "넌 해고야!"가 마지막에 **"넌 해고가 아니야. 넌 가족이야"**로 뒤집힌다. *그리고 펑거스 역시 결국 "이 집에 속하고 싶었던" 거울상* — 치즈는 얻었고 펑거스는 빼앗긴 같은 열망이었음이 드러나며, 적이지만 가여운 라이벌로 마무리(화해/일원으로 받아들임의 여지).

## 3. 코어 게임플레이

| 요소 | 결정 |
|---|---|
| 화면 | 가로. 왼쪽 = 집(밥그릇), 오른쪽에서 적이 밀려옴. **단일 화면 고정(카메라 스크롤 없음)** — 적 전체가 한눈에 |
| 치즈의 역할 | **살아있는 프론트라인(관문).** 적은 치즈 앞에서 싸우고, 치즈가 죽어야만 지나친다 |
| 이동 | 화면 왼쪽~2/3 구간을 **좌우로 드래그**(자유 2D 아님). 멀리 못 빠지니 *정밀한 간격 싸움* |
| 회피 | **탭으로 점프 = 회피 전용.** 점프해도 적은 통과 안 함, 공격 타이밍만 흘림 |
| 밀기 | **전진하면 앞 적을 몸으로 밂.** 적이 *멈췄을 땐(공격 중) 누구나*, *움직일 땐 이동속도>적*일 때만. *막힌 적 3마리 넘으면 못 밂.* 미는 동안 맞음(체력 트레이드오프) → 적 패턴 학습이 실력 |
| 공격 | **자동 조준 사격**(원거리) + 코앞 적은 근거리. 모든 직업이 근·원 다 되되 무게중심이 다름 |
| 스킬 발동 | **쿨타임** 기반. 스킬은 *동전으로 사서 슬롯에 장착* |
| 적 등장 | **웨이브** 기반 |
| 실력의 핵심 | 거리(간격) 관리 + 점프 회피 타이밍 + 밀기 판단 + 빌드 선택 |

**조작은 드래그 + 탭 두 개뿐** — 모바일 한 손에 맞춤. 이미 제작된 모션(walk·jump·shot·hit)이 모두 여기서 제 역할을 한다. *(근접 공격 모션 + 뒷걸음질 모션 추가 제작 필요)*

### 실패 & 재고용 루프
치즈 HP 0 → 적이 집으로 우르르 → **게임오버** → 쫓겨나는 코미디 연출 → "집주인이 한 번 더 기회를 준다"는 컷 → **실패한 그 스테이지 재도전(자산 전부 유지)**. 강제 리셋 없음. 깬 스테이지는 파밍용으로 반복 플레이 가능.

## 4. 진행 구조

- **스테이지 맵:** 큰 막마다 스테이지 1-1 ~ 1-20. **1-10 중간보스, 1-20 최종보스** → 다음 막.
- **막마다 새 적 1종 + 새 환경 기믹 1개**만 추가 (스테이지 20개의 단조로움 방지).
- 웨이브는 서브스테이지 안에서도 점증(수량↑ → 종류 혼합 → 정예 1).
- 아트·연출 화력은 **보스(10·20)에 집중**.
- **플레이 타임:** 일반 스테이지 1~2분 / 보스 2~4분. 콘텐츠 고갈은 *판을 늘려* 풀지 말고 *다시 할 이유*(빌드·파밍·점수·다른 직업)로 푼다.
- **막 전환 컷신:** 1930년대 신문 헤드라인 몽타주(고전 영화 클리셰)로 통일 — "전설이 자랐다 + 펑거스가 다음 패거리를 모은다 + 카메라가 집 안쪽으로 한 발 더" 를 한 장치로 처리.

## 5. 스토리 — 5막 구조

**공간 논리 = 침입자가 한 겹씩 집 안으로 + 점점 미쳐감.** 담벼락(밖) → 마당(부지 안) → 거실(집 안) → 주방·침실(깊숙이) → 금고(핵심). 동시에 현실(해충·야생·도둑) → 비현실(호랑이·괴물·외계인). 두 축(공간 침투 + 광기 상승)이 같이 진행.

| 막 | 무대 | 적 (테마) | 보스 / 비트 |
|---|---|---|---|
| 프롤로그 | 비 오는 거리 → 저택 | — | 치즈가 거둬짐. *입양 첫날, 치즈가 영감에게 잘 보이려 집에 살던 쥐(펑거스)를 잡아 걷어차 쫓아냄 → 펑거스 추락의 시작이자 치즈 신임의 계기.* 영감이 세계일주 떠나며 "쥐새끼 한 마리라도 들이면 길바닥". 이후 전보/전화로만 등장 |
| **1막** | **담벼락 (집 밖 울타리)** — 돌담·대문 앞 | 해충 — 쥐·바퀴벌레·박쥐 | **중간보스(1-10) 펑거스 본인**(구두 개조차 무장) / **최종보스(1-20) 큰 뱀**(펑거스가 마당서 꼬셔온 첫 야수, *쥐 아닌 충격*) → 2막 예고 |
| **2막** | **마당·정원** — 잔디·화단·분수·창고 | 야생 — 까마귀·너구리·두더지·들짐승 | 중간보스 펑거스(무장2) / 최종보스 야생 두목(너구리 도적단장 등). 끝에 인간 그림자 등장(떡밥) |
| **3막** | **현관·거실** (드디어 집 안!) — 소파·벽난로·카펫 | 인간 도둑단 (고전 도둑 코미디 오마주) | 도둑 두목. **함정 코미디 절정.** ★**3막 = 1차 출시 마무리 지점.** 끝에 초록빛 섬광(외계 떡밥) |
| **4막** | **주방·침실·다락** (집 깊숙이·사적 공간) | 초현실 코믹호러 — 호랑이·괴물 | 호랑이/괴물. *현실→비현실 전환점.* 전설이 우주로 송출됨(떡밥) |
| **5막** | **최심부·지하 금고** (집의 핵심) | 외계인 (+펑거스 최종) | 외계 대장. **반전(보물 = 입양 서류 = 치즈 자신) + 영감 귀환(첫 얼굴 공개) + "넌 가족이야"** + 펑거스도 "속하고 싶었던 거울상"으로 마무리 |

> **막 안 세분화:** 한 막(20스테이지)을 *한 배경으로 채우면 지루* → 막 안에서도 작은 변화를 준다. 예: 2막 1~10 앞뜰(낮) → 11~20 뒷뜰·창고(해질녘). 같은 테마 안에서 *조명·소품·시간대*를 바꿔 신선함 유지.
> **비주얼 점층:** 1막(소박한 담, 현실·밝음) → 5막(화려한 SF, 초현실)으로 점점 화려·기괴. 아트 난이도도 점진 상승(제작에 유리).

## 6. 주요 캐릭터

- **치즈** — 주인공. 본체 스탯 고정, 모든 힘은 장비에서.
- **펑거스 (라이벌 생쥐)** — 원래 골드의 집에 살다 치즈에게 쫓겨난 쥐. *치즈와 운명이 뒤바뀐 거울상.* 집으로 돌아오려 매 막 더 센 세력을 끌어옴 = 모든 침공의 숨은 근원.
- **골드 영감** — 주인. 직접 등장 없이 전보/전화로만.
- **맥스 (검은 도둑고양이)** — **상시 정규 상점.** *부자 동네에서 잔뼈 굵은 길거리 상인*(부유하진 않고 부와 거리의 경계에 선 시선, 염세적이지만 단골은 챙기는 츤데레). 치즈와 *같은 길거리 출신* = 치즈의 과거를 비추는 거울. 1-5 이후 항상 있음(1-5 소모품 → 1-7 직업 → 1-9 스킬·확장). 동전으로 안정 판매.
- **라쿤 (너구리)** — **떠돌이 특수 상점. 첫 등장 = 2막 시작**(1막은 해금 과밀 + 맥스에 먼저 익숙해진 뒤라야 임팩트). 이후 가끔 무작위 등장. 진귀템(희귀 직업·한정 코스튬·고가 스킬·특이 소모품·*보석*), FOMO 유발. 밀수 직업(닌자 등) 공급처 + 한정 이벤트 자리(라이브 운영의 씨앗).
- **펄 (흰 페르시안 히로인)** — **출격 축복 + 호감도(로맨스).** *옆집 부잣집 아가씨* — 곱게 자란 우아·페미닌. **창가에서 늘 치즈의 고군분투를 지켜보며** 관심→팬→연인으로(거리도 창가→마당→곁으로 점차 좁혀짐). 1-5 해금. 진입 전 축복 1개 택1(맹수의 발톱=공격 / 튼튼한 배=체력 / 부자집 곳간=동전). **호감도 = 보석 헌납**(드랍한 보석을 *팔아 동전* or *바쳐서 호감도*, 보석별 수치 차등, 게이지 표시). **Lv1~5: 축복 2배 강화(15→30%) + 썸 컷신(눈빛→뽀뽀) + 호칭 변화(치즈 선생님→씨→오빠(존댓)→오빠(반말)→자기야 / Sir→Mr.→Cheese→dear→Honey)**, Lv3 크리율·Lv5 펄의 가호 축복 해금, 최고 단계 연인→데이트 미니게임(라이브 후속). *선택적 깊이 — 안 해도 완주 가능, 카툰풍 가벼운 로맨스.*

## 6-B. 대사 & 연출 (1막)

### 톤 원칙 — "컷신은 사일런트, NPC는 대사"
1930년대 카툰(톰과제리·컵헤드) 감성. 두 종류를 분리한다:
- **컷신(스토리 장면) = 사일런트 중심.** 감정·사건·액션은 표정·몸짓·만화 기호(하트💗·김💢·물음표❓·전구💡)로 전달. 모바일 스킵 대응 + 글로벌 번역 부담↓. **단 *규칙·정보를 전달하는 NPC 대사*(영감의 당부, 펑거스의 동기·선전포고)는 명확히 글자로 넣는다.**
- **NPC 상호작용 = 대사 있음.** 맥스(상점)·펄(축복)·라쿤은 캐릭터 톤대로 짧게, 여러 줄 로테이션(반복해도 안 질리게).

### 캐릭터 말투 톤
- **치즈 (주인공): 전 구간 무대사.** 말풍선 텍스트 없이 *표정·몸짓·만화 기호*로만 반응(톰처럼 말없이 능청맞음). → 플레이어 이입 ↑.

- **펄: 우아한 새침 존댓말 → 점점 수줍게 무너짐.** 호감도 따라 호칭·말투 변화(선생님→자기야).
- **맥스: 시니컬·짧게.** 정 없는 척, 돈 밝히는 척, 가끔 속내 샘("…죽지나 마라"). 뒷골목 말투.
- **펑거스: 비굴+거창한 코믹 빌런.** 쩨쩨한데 대단한 척, 복수심에 부들부들, 가끔 진짜 한이 서림. *말이 많아도 됨*(치즈의 무대사와 대비).

**원칙:** 치즈 본체 스탯 고정 → 모든 힘·스킬·다양성은 장비에서 → 레벨 디자인이 항상 예측 가능.

**구조 결정(중요):** 부위별 믹스앤매치를 버리고 **통짜 "클래스(직업) 세트"** 로 간다. "보안관 치즈 / 메이드 치즈 / 음악가 치즈"처럼 한 벌 통째로 장착. 이렇게 한 이유:
- **외형 문제 해결.** 부위별 오버레이 합성이 필요 없다. 직업당 전체 애니메이션 한 벌만 그리면 된다(AI 아트로 *일관된 컨셉 한 벌* 뽑기가 부위 합성보다 쉬움).
- **선택이 선명.** "최적 조합 찾기" 숙제가 아니라 "이번 판 어떤 치즈로?"라는 직관적 선택. 직업 = 플레이스타일 한 묶음.

### 두 개의 축: 직업 × Lv
- **가로축 = 직업(플레이스타일):** 보안관/메이드/음악가… → "어떻게 싸우느냐"
- **세로축 = Lv(파워): Lv1~5 (이름없는→떠오르는→소문난→이름난→전설의)** → "얼마나 세냐"
- 모든 세트 = `직업 × Lv` 좌표 하나(예: "닌자 치즈 Lv3(소문난)"). *어느 스테이지에서 가질 수 있는 최대 Lv을 해금·가격으로 통제* → 통제된 파워 유지.
- **Lv 표시명은 "평판 형용사"**(이름없는~전설의)라 어떤 직업명에 붙어도 충돌 없음("이름 없는 보안관", "전설의 메이드"). 세계관 척추(소문→전설)와 일치. 직업마다 *존재하는 Lv 구간이 다름*(보안관 Lv1~5 / 산타 Lv3 고정 등). UI에선 별·색 병행으로 순서 표시. 내부 데이터는 숫자(Lv1~)라 천장 확장 자유(Lv6+ "신화의").

### 슬롯 구조 (단 2슬롯 + 소모품)
| 슬롯 | 역할 |
|---|---|
| **세트(직업) 슬롯 1** | 통짜 한 벌. 외형·무기(근/원)·스탯·상시 패시브가 여기 묶임. 스킬은 *별도 구매해 슬롯에 장착*(아래). **유일하게 외형에 드러나는 슬롯.** |
| **동료 호출 스킬 슬롯 1** | 외형 없는 액티브 스킬 슬롯(구 "목걸이"). 호루라기형 동료 소환. 쿨타임 기반. |
| 소모품 칸 2~3 | 1회용 전술템: 회복·폭탄·츄르 + (3막~) 함정 트랩(페인트통·다리미·구슬 등 고전 슬랩스틱) |

> 외형을 신경 쓸 슬롯이 **세트 하나뿐** → "장비마다 새로 그리기" 문제 소멸. 모바일 장비 화면도 최소.

### 스탯 5칸 (방어력은 체력에 통합)
원거리공격력 · 근거리공격력 · 공격속도 · 체력 · 이동속도.
세트 아이템 하나가 이 5칸을 모두 보유하고 숫자만 다르다. **직업이 배분 성향**(메이드=근접↑/원거리↓, 음악가=원거리↑/체력↓, 보안관=균형), **Lv이 전체 크기**를 정한다.
**모든 직업은 근접·원거리 평타를 다 가짐**(무게중심만 다름). **크리티컬 = 직업 개성 장치**: 평타엔 약한 기본효과, 크리 터지면 그 직업다운 강효과(메이드=강넉백 / 음악가=스턴 / 보안관=강타). 크리율은 직업 고정값(스탯 칸 안 늘림), 스킬은 그 효과의 *확정 버전*.

### Lv별 배율 & 스킬 장착 슬롯
| Lv (표시명) | 공격력·체력 배율 | 스킬 장착 슬롯 |
|---|---|---|
| Lv1 이름없는 | 1.0 | 2 |
| Lv2 떠오르는 | 1.5 | 2 |
| Lv3 소문난 | 2.2 | 3 |
| Lv4 이름난 | 3.2 | 3 |
| Lv5 전설의 | 4.5 | 4 |

- 공격속도·이동속도는 직업 고유값으로 Lv에 거의 불변(폭주 방지).
- 슬롯 = "장착 칸". Lv업 시 **Lv3에서 3번째 칸, Lv5에서 4번째 칸**이 열리고, Lv4·5에서 직업 *시그니처 패시브*도 강화 → "Lv5 찍을 이유". (천장 4 = 모바일 한 손 조작 한계)
- *상시 패시브는 세트에 내장*(구 "부적" 역할 흡수).

### 스킬 = 구매·장착식 (핵심)
스킬은 직업에 자동으로 딸려오지 않는다. **상점(맥스·라쿤)에서 동전으로 사서 슬롯에 골라 장착.**
- **직업 귀속:** 보안관 스킬은 보안관만. 범용 금지(직업 정체성 + 밸런스를 직업 안으로 한정).
- **직업당 스킬 풀 ≈ 3개**(1막 기준). 슬롯이 보유 스킬보다 적으면(예: 3개 보유 / Lv1·2 = 2슬롯) **"어느 2개를 끼울까" 선택**이 생김 → 세 스킬은 *역할이 겹치지 않게* 설계(광역 청소 / 생존 / 단일 폭딜 등).
- **사 모으는 재미 = 질림 방지.** 스킬이 한 번에 다 주어지지 않고 획득 곡선을 탄다. 직업 수가 적어도 스킬 수집·조합으로 다양성 확보.
- **강력 스킬은 라쿤(가끔)·고가** → "낮은 Lv + 좋은 스킬" 하이리스크 빌드 가능.

### Lv ↔ 스킬 상호 보완 (밸런스 핵심 원리)
Lv업(스탯↑)과 스킬 구매(능력↑)는 전투력을 채우는 **두 개의 축**. 한쪽이 부족하면 다른 쪽으로 메운다.
- 설계 목표: **`D + 좋은 스킬 ≈ C + 기본 스킬`**, *총 전투력·총 비용이 엇비슷.*
- 결과: **안정형**(동전을 Lv에 투자) vs **영리형**(동전을 스킬에 투자) 둘 다 유효.
- **Lv은 강제 게이팅 아님.** 막마다 권장 Lv은 있으나, 한 단계 아래 + 좋은 스킬 + 실력으로 돌파 가능. (예: 1막 전체가 Lv1 + 스킬 2개로 클리어 가능, Lv2는 "있으면 쉬움")

### 직업의 Lv 범위 차등 (운영·수익과 연결)
모든 직업이 Lv1~5를 다 가질 필요 없음. 직업마다 존재 구간이 다르고, 그게 곧 성격·출처를 말한다.
- **풀 라인(Lv1~5)** = 기둥 직업(보안관·메이드·음악가). *조연은 좁은 범위 가능(정원사 Lv1~4 등).* *무과금 성장의 핵심 — 절대 유료 게이팅 금지.*
- **고급 한정(Lv4·5만)** = 끝판·진귀 직업(마법사·슈퍼히어로). "입문용이 아닌 끝판 장비".
- **단일 Lv(한 Lv 고정)** = 시즌·이벤트·유료 직업(핼러윈 유령·산타 등). 성장 시스템 밖이라 밸런스 관리 쉬움.
- **유료 직업 원칙:** "더 셈"이 아니라 **"다르게 놂 + 수집"** (Pay-to-Win 금지). 무과금 최강보다 세면 안 됨.

### 동료 = 호루라기형 (별도 시스템 아님)
거리에서 *사귄 친구*를 호루라기로 부른다. 동료 호출 슬롯 1개에 장착 → 매 판 택1, 쿨타임 기반.
- **획득 = 만남(공짜 이벤트, 정서) + 호루라기 구매(맥스, 동전 ~200~300).** "산 용병"이 아니라 *사귄 친구* → 길고양이 치즈의 정체성. 둘 다 사귀어도 호루라기는 각각 사야 함(우선순위 선택).
- **1막 2종 (둘 다 딜보다 유틸 — 원거리 딜러와 시너지):**
  - **치와와**(넉백·지상): 좌→우로 컁컁 달려 *막힌 지상 적을 전부 오른쪽 끝까지 밀어냄*(데미지 거의 없음, 밀기 규칙 무시). *단 지상 전용 — 공중의 박쥐는 못 밂.* *공간·시간 리셋* — 닌자·음악가가 거리 확보. 1-13 만남(+동료 튜토리얼). CD ~30s.
  - **비둘기**(둔화·공중): 똥 폭격으로 맞은 적 *둔화*(끈적임). 박쥐 대응+전체 둔화로 밀기·사격 보조. 1-16 만남. CD ~22s. (음악가 스턴과 결 다름)
- 호루라기(1930년대 소품)는 외형이 아니라 *UI 아이콘·연출*로만. 새 동료 = *만남 이벤트(무료) + 맥스 호루라기 판매(유료)* 패턴 반복(라이브 확장 용이). 황소 등 큰 체급은 후반 막(큰 적)용으로 보류.

### 직업 해금 = 스토리 진행 (두 갈래)
- **노획형(스토리 직업):** 적에게서 빼앗거나 저택에서 발견. 막 클리어 시 획득 또는 맥스 상점 해금. (보안관=집 지킴이, 갱스터=갱단 노획, 발명가=영감의 발명품)
- **밀수형(라쿤 직업):** 출처가 이국적인 것. 라쿤이 가끔 들고 올 때 동전 구매(FOMO). (닌자·사무라이·파라오 = "바다 건너온 물건")
- **현실 → 황당 곡선:** 적이 쥐→외계인으로 미쳐가듯 직업도 같은 곡선. 1군 현실(집/길에 있는 것) → 2군 노획 → 3군 황당(후반 초현실·우주). *길냥이가 처음부터 마법사면 톤이 깨짐* → 직업 출처가 항상 설명되게 배치.

### 코스튬 (외형) — 성능과 분리
순수 꾸미기 레이어를 세트 성능과 별도로 둔다(색·테마·치장). "강한데 못생긴 세트를 억지로 끼는" 문제 방지 + 자발적 결제 포인트. *(우선순위 낮음, 슬라이스 이후)*

### 네 가지 특수효과 발동 시점 (서로 안 겹침)
펄의 축복 = **판 시작 전 선택** · 세트 패시브 = **상시** · 동료 호출 = **판 중 호출(쿨타임)** · 세트 고유 스킬 = **쿨타임**.

> **상세 수치(스탯 값·Lv 배율·직업별 데이터·적 상관관계·재화·스테이지 난이도)는 별도 문서 〈시스템 & 밸런스 설계서 — 1막〉 참조.**

## 7-B. 화면 구조 (IA / UX)

**가로형(랜드스케이프) 전제.** 하단 풀폭 탭바는 안 씀(가로엔 부적합) → *양손 엄지가 닿는 좌우 모서리*에 조작, *상단 얇은 바*에 정보. 홈은 **혼합형**(저택 풍경 배경 + 모서리 UI).

### 전체 화면 맵
```
[스플래시/타이틀]
   └→ [홈] ★메인 허브
        ├→ [전투 준비]  (직업·스킬·동료·소모품 탭)
        ├→ [상점/맥스]  (직업·스킬·소모품·호루라기 구매)
        ├→ [펄]         (축복 선택 · 호감도/보석 헌납 · 컷신)
        ├→ [스테이지 맵] (이전 스테이지 선택·파밍)
        ├→ [설정]
        └→ [출격] → [전투] → [결과] → 다음 스테이지 or 홈
```

### 홈 화면 레이아웃 (혼합형)
```
상단 바:  💰 동전          [현재 막 · 예: 1막 담벼락]          ⚙ 설정
중앙 풍경: 저택 배경 + 🐈 치즈(대기) · 🪟 펄(옆집 창가) · 🐈‍⬛ 맥스(수레)
좌하단(왼손): [전투 준비]
우하단(오른손): [출격 ▶] (크게) + [맵] (작게)
```
- **기능을 캐릭터 위치로 분산(몰입):** 맥스 수레 탭→상점 / 펄 창가 탭→펄 화면 / 치즈 관련 세팅→[전투 준비]. 처음 유저용으로 *모서리에 작은 아이콘도 중복* 가능(오브젝트=몰입, 아이콘=명확).
- **펄 위치 연출:** 호감도 오르면 창가→마당→곁으로 점차 다가옴(거리 좁히기).
- **상단 바 = 동전만**(유일한 합산 재화). *보석은 재화 아님 → 상단에 없음.* 보석은 종류별 아이템(조약돌~다이아)으로 펄 화면 인벤토리에서 처리(팔기=동전 / 바치기=호감도).

### [전투 준비] 화면 (치즈 세팅, 탭 전환)
- **직업:** 세트 선택(보안관/메이드/음악가/닌자…), 보유 직업 목록
- **스킬:** 직업 슬롯에 스킬 장착(3개 중 2개), Lv 업그레이드
- **동료:** 호루라기 장착(보유 동료 중 슬롯 1개 택1)
- **소모품:** 전투 휴대(회복·폭탄·츄르)
- *부위별 장비 인벤토리는 없음*(직업 세트 통짜 구조). 위 4탭이 세팅의 전부.

### 펄 화면 (창가 탭)
- **축복 선택:** 출격 전 1개 택1(공격/체력/동전 + 호감도 해금분). *축복은 전투 버프뿐 아니라 수급(곳간)도 있어 "전투 준비"가 아닌 펄 화면 소속.*
- **호감도/보석:** 보유 보석을 팔기(동전) or 바치기(호감도), 게이지·레벨 표시
- **컷신:** 호감도 레벨업 시 재생

### 출격 흐름 = 마찰 없는 연속 플레이
- 스테이지 클리어 → **이벤트 없으면 [다음 스테이지 ▶] 바로** / **이벤트 있으면**(펄 해금·동료 만남·보스 등) 컷신·해금 표시 후 진행.
- 결과 화면: [다음 스테이지 ▶](크게) + [홈으로](작게). *세팅은 강제 안 함* — 하고 싶으면 홈 가서 [전투 준비]·펄·상점. 쭉 진행하려면 계속 [다음].
- [출격]=현재 진행 스테이지로 바로 / [맵]=이전 스테이지 골라 파밍.

### 전투 HUD (가로) ★실제 손맛의 핵심
**원리:** 상단=정보(안 가림), 하단=조작 영역. **왼손=위치 컨트롤, 오른손=능력 발동, 가운데=소모품.** 가상 조이스틱 없음(좌우 이동만이라 불필요).
```
상단:  ❤️ HP 게이지바(+숫자)      [≡ 일시정지]      🌊 웨이브 3/5
중앙:  🏠치즈(왼쪽~2/3 구간)  ………………  적들(오른쪽 등장)  / 바닥 라인
하단:  [왼손]              [가운데]            [오른손]
       ←→ 드래그=이동       소모품 슬롯 2~3       스킬 2~4
       탭=점프(회피)        (세팅한 것만)         동료 호출 🐶
```
- **왼손 (위치 컨트롤):** 화면 왼쪽 영역에서 *좌우 드래그=이동*, *탭=점프(회피)*. 가상 패드 없이 터치로. 드래그(밀기)와 탭(톡)은 동작이 달라 안 헷갈림. → 이동+회피를 한 손이 전담하니 오른손과 충돌 없음.
- **가운데 (소모품):** 슬롯 2~3칸. **전투 중 쓸 수 있는 아이템만 세팅 가능**(회복·폭탄·츄르 등), 세팅한 것만 표시·사용. *보석류(다이아 등)는 전투템 아님 → 세팅 목록에 안 뜸.* 슬롯은 범용 → 새 소모품(설치형 함정 등) 추가 시 목록에 끼우기만(등장 시점은 개발하며 결정, 열어둠). 가끔 쓰니 가운데.
- **오른손 (능력 발동):** **스킬 버튼**(쿨타임 표시) + **동료 호출 버튼**(쿨타임). *착용 직업의 장착 상태대로 가변* — Lv 따라 스킬 2~4개, 끼운 스킬만. **자리는 최대치(스킬 4 + 동료 1)로 확보**해 늘어나도 레이아웃 안 깨짐. 자주 쓰니 오른손.
- **상단 (정보, 얇게):** **HP 게이지 바 + 숫자**(직업·Lv마다 체력 130~650+ 다르니 바가 맞음, 유일한 실패 게이지라 가장 명확히) / 일시정지 [≡] / 웨이브 진행(N/M). 전투 화면 안 가리게.
- **일시정지 →** [계속][설정][포기]. **클리어 →** 결과(보상·다음·홈). **실패 →** 게임오버 연출 → 재도전.

## 9. 출시 전략

**원칙: 콘텐츠는 작게, 시스템·완성도는 100%.**

- **1차 출시(1.0) 범위:** 1~3막(= 완결된 캠페인) + **코어 시스템 전체.**
  - 필수 시스템: 스토리모드, 상점, 장비/장착, 재화(동전), 세이브/로드, 게임오버-재고용 루프, 설정, 깬 스테이지 재도전.
  - 반복 콘텐츠(엔드리스 등)는 출시 후로.
- **체크포인트 원칙:** 1막을 *출시 가능한 완성도*까지 먼저 만들고 멈춰 **① 코어가 재밌나 ② 내 개발(코드·아트 일관성) 속도가 어느 정도인가**를 검증 → 그 뒤 3막 풀악셀. (1막 완성은 버리는 작업이 아니라 *되돌릴 수 있는 체크포인트*)

**단계:** ① 프로토타입(비공개, 1-1~1-3 + 보스 1) → ② 베타(TestFlight) → ③ 소프트런치(1~2개국) → ④ 글로벌 1.0(1~3막) → ⑤ 업데이트(4·5막, 이벤트).

- **출시국·언어 (§10-5 정렬):** 빌드엔 **다국어를 풀 장착**(한·영·일·중·독·불 등 — 컷신이 사일런트 중심(§6-B)이라 번역 부담↓). 출시 스위치는 단계적 — **1단계 소프트런치 = 한국(제작자 네이티브) + 캐나다/호주(영어권 테스트 베드, UA 경쟁 덜함)**, **2단계 글로벌 = 미국 + 한국 + 영어권 전체 + 서유럽**(소프트런치에서 치명버그 없을 때). 다국어가 빌드에 이미 있으니 확대는 *추가 제작 없이 스위치만*. 상세 §10-5.

**참고 사실:** 스토어 등록비 — 애플 $99/년, 구글 플레이 $25 1회(구글 *개인* 계정은 출시 전 테스터 12명·14일 비공개 테스트 요건). 엔진 — Unity Personal은 매출 $200K 미만 무료(런타임 수수료 폐지됨), Godot는 MIT 라이선스로 완전 무료·2D 강점. 둘 다 맥에서 iOS/안드로이드 양쪽 빌드 가능.

> **AI 아트 전제의 새 병목:** 콘텐츠 양은 더는 1순위 제약이 아님. 대신 ① 에셋 간 *스타일 일관성*, ② *애니메이션 프레임 일관성*, ③ **게임 코드/로직(충돌·적 AI·웨이브·세이브·밸런싱)**이 진짜 병목. 아트가 빨라도 코드는 빨라지지 않으므로 일정 과소평가 주의.

## 10. 수익 모델 (BM)

> **2026-06-02 갱신본(기획 챗 확정).** 연결: §6(펄·코스튬), §7-B(홈 화면), §9(출시 전략), `기획_홈인터랙션.md`(애착 엔진).

### 10-0. 대전제 — "수익은 BM이 아니라 다운로드가 결정한다"

이 게임은 **싱글플레이 · 단일 히어로 · 5막 완결 스토리 · PvP 없음**이다.
→ 고수익 F2P 엔진(경쟁·무한성장·소셜압박·가챠)이 구조적으로 없다. 고래가 파워에 돈 부을 동기가 없으므로 **1인당 결제액(ARPU) 천장이 낮다.**

따라서 수익 공식에서 **거의 모든 변수는 "몇 명이 깔았느냐(다운로드)"이고, BM 설계는 그 위에 얹는 변환 장치일 뿐**이다.
(아래 수익 모델 표 참조: 광고·IAP 가정을 고정해도 다운로드 5천 → 10만으로 가면 수익이 약 20배 차이.)

**목표 설정(현실):** 무명 1인 개발 첫 게임의 현실적 기댓값은 누적 다운로드 **5천~2만** 구간.
→ "잘되면 용돈, 대박 나면 월세 보조, 평균은 가벼운 보너스." **이 게임으로 생계를 기대하지 않는다.** 진짜 자산은 ① 완성·출시 경험 ② 모은 관객 ③ 재사용 가능한 아트/코드 → *다음 게임*의 발판.

### 10-1. 대원칙

- **Pay-to-Win 금지.** 돈으로 파워(스탯·진행 우위)를 팔지 않는다. 싱글게임이라 돈도 안 되고, P2W는 리뷰만 깎아 유일한 레버인 *도달*을 죽인다.
- **애정 자체를 팔지 않는다.** 펄 호감도·치즈 친밀도 등 정서 콘텐츠는 전부 무료. 그 애착이 *외형(코스튬)·응원(팁)*으로 흐르게 한다.
- **노동 대비 수익(ROI) 우선.** 매출 기대값이 낮으므로 BM에 시간을 많이 쏟는 것 자체가 손해. **아트 노동 위주(코스튬) + 한 번 붙이면 끝(광고)**만 채택.
- **재미와 수익이 같은 방향.** 애착 엔진(홈 인터랙션·펄·컷신·스토리)을 잘 만들수록 코스튬·팁이 팔린다. 돈 벌려고 게임을 비틀 필요가 없다.

### 10-2. 수익원 라인업

#### ✅ 출시 1.0에 포함 (노동 적고 게임 안 망침)

1. **리워드 광고 (가장 가성비 높음)**
   - 게임오버 후 "광고 보고 부활" / "광고 보고 동전 2배" / "무료 상자".
   - 유저가 *자발적으로* 보는 옵트인 → 거부감 최저, 완료율 높음.
   - SDK 한 번 붙이면 끝. 도달에 비례해 자동 수익.
   - **전면(인터스티셜) 광고는 신중히** — 1~2분 타이트 액션 흐름을 끊으면 리텐션·평점 하락. 넣더라도 빈도 엄격 제한, 또는 출시 후 검토.

2. **광고 제거 (1회 결제, ⚠️ 구독 아님)**
   - 한 번 결제로 광고 영구 제거. **월 구독 금지** — 일회성 기능을 구독으로 받으면 (a) 안 사고 (b) 애플 심사 리젝 위험 (c) 리뷰 악화.

3. **시즌 코스튬 (외형, 성능 분리)**
   - "핼러윈 유령 보안관", "산타 메이드", "벚꽃 음악가" 등 **기존 직업 위에 입히는 순수 겉옷(스탯 동일).** §6 "코스튬 — 성능과 분리" 원칙 준수.
   - ⚠️ **시즌 "직업"을 새로 파는 게 아님** — 새 성능을 팔면 P2W. 반드시 기존 직업 스킨으로.
   - **시즌 한정 = FOMO** ("지금 아니면 못 삼"). 라쿤 상점(§6, 한정·가끔 등장)에 얹기 좋음.
   - 코스튬은 IAP 중 가장 수익성 높은 카테고리. 단일 히어로라 시장이 크진 않으나 안정적 보조 수입.
   - 그래픽 디자이너인 제작자의 강점과 직결 → "만드는 게 즐거운데 팔리기까지 함."

4. **후원 팁 ("츄르 사주기", 강추)**
   - 순수 응원 결제. 보상 없음 또는 아주 작음(감사 컷신·크레딧·한정 색 1개).
   - 정서 강한 게임(길냥이가 집 지킴)은 애착 유저가 "그냥 응원하고 싶어" 누르는 돈이 의외로 나옴. 노동 거의 0.

5. **스타터 팩 (첫 결제 한정 오퍼)**
   - "첫 N일 한정: 코스튬 2~3개 + 광고제거 묶음." 신규 전환율 최고 단일 상품.
   - 이미 만든 것들을 *묶기만* 하면 됨(새 노동 거의 0). "한정" 표시로 결제 유도.

#### 🕒 출시 후 (게임이 살아있고 콘텐츠 공급 리듬이 생기면)

6. **배틀패스 (시즌 패스)**
   - 무료 트랙 + 유료 트랙(코스튬·동전·한정 직업 스킨). 모바일 최강의 *반복* 수익원.
   - **단, 매 시즌 새 보상을 계속 공급해야 작동 + 코드 무거움**(진행도 추적·보상 지급·시즌 리셋).
   - **5막 완성 → 게임 생존 확인 → 그때 검토.** 본편 전에 넣으면 노동만 크고 회수 안 됨.

7. **코스튬 번들 / 색 변형**
   - 시즌 전체 묶음 할인(객단가↑) + 같은 코스튬 색 변형(노동 거의 추가 없이 SKU 수↑).

#### 🚫 절대 넣지 않음 (보너스 목적에 독)

- **동전 현금 판매(현금→파워):** 소프트 P2W. 싱글게임이라 돈도 안 되고 리뷰만 깎임. **재화(동전)는 인게임 파밍 전용.**
- **가챠:** 노동 큼(확률 시스템·법적 확률 표시 의무), 톤 안 맞음, 리스크만.
- **PvP·기지 꾸미기:** 서버·매치메이킹·영구 밸런싱 필요 → 1인·코딩 초보 단계에선 다른 게임이 됨. "성공하면 다음 작품" 서랍에.

### 10-5. 출시 전략 — "다국어 풀 장착 + 단계적 출시 스위치"

**핵심: 다국어는 적극 준비하되, 출시 스위치는 한 발씩.**

- **서버비는 사실상 0** — 싱글플레이라 게임 서버 불필요. 세이브도 iCloud/Google Play Games 무료 기능으로 충분(서버비 X, 단 구현 노동은 있음).
- **다국 동시 출시의 진짜 비용은 번역·서버가 아니라:**
  1. **첫인상을 한 번에 다 태움** — 무명 게임은 출시 직후 평점이 굳고, 낮은 초기 평점은 노출 알고리즘에 영구히 따라붙어 회복 거의 불가. 1인 첫 빌드엔 버그·밸런스 이슈가 거의 확실 → 큰 시장에 그대로 노출하면 치명적.
  2. **현지화 = 운영** — 나라 수만큼 늘어나는 것은 번역량이 아니라 *관리할 채널 수*(스토어 심사·리뷰/CS·스토어 등록정보 최적화·연령등급/법규).
  3. **법규 표면적** — 광고/결제 있는 아동친화 톤 게임은 나라별 아동광고·소비자보호 규제(COPPA/GDPR-K 등) 확대.
  4. **가격 현지화** — 구매력 차이. 환율 단순변환은 최적 아님 → 나라별 손질 시 수익↑.

**그래서 권장 플로우 (총알은 다 장전, 방아쇠는 한 발씩):**

- **빌드엔 다국어를 가능한 만큼 다 넣어둔다** (제작자가 다국어 가능 → 한·영·일·중·독·불 등). 컷신이 "사일런트 중심"(§6-B)이라 번역 부담이 작은 게 강점.
- **단계적 출시 스위치:**
  - **1단계 소프트런치(1~2개국):** 한국(제작자 네이티브 → CS·커뮤니티·피드백 즉시) + 캐나다 또는 호주(영어권·미국보다 UA 경쟁 덜함·tier-1급 광고단가 → 영어 빌드 테스트 베드).
  - **2단계 글로벌 확대(소프트런치에서 치명버그 없으면):** 미국(광고단가·결제력 최고) + 한국(리워드 eCPM 최상위권) + 영어권 전체 + 서유럽.
  - 다국어가 이미 빌드에 있으니 글로벌 확대는 *추가 제작 없이 스위치만* 켜면 됨.
- **CS·스토어 최적화 감당 안 되는 언어:** 빌드엔 넣되 마케팅·집중 관리는 한·영 중심(플레이는 되게, 시장 "공략"은 선택).

### 10-6. 선행 과제 (BM 작동 전 필요)
