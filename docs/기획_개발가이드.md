## 🎮 게임 한 줄 요약
1930년대 카툰풍(컵헤드 톤) **횡스크롤 액션 디펜스**. 고양이 **치즈**가 살아있는 방어선이 되어, 오른쪽에서 밀려오는 침입자로부터 집을 지킨다. **iOS 우선 · 가로 모드 · 2D.** 엔진: **Godot 4**.

## ⚠️ 개발 원칙 (중요 — 꼭 지켜주세요)
1. **한 번에 다 만들지 않는다.** 아주 작은 조각부터 하나씩 구현하고, 각 조각이 *실제로 작동하는 걸 확인한 뒤* 다음으로 넘어갑니다. ("치즈 좌우 이동"이 되고 나서 "점프"로.)
2. **임시 비주얼로 먼저, 그림은 나중에.** 스프라이트(그림)는 개발자가 직접 1930년대 카툰풍으로 그려서 나중에 교체합니다. 처음엔 컬러 사각형 같은 임시 도형으로 *동작*부터 검증합니다. ("회색 박스로 먼저, 꾸미기는 나중에.")
3. **수치는 시스템밸런스 문서를 따른다.** 체력·공격력·이동속도·밀기 등 숫자는 임의로 정하지 말고 `기획_시스템밸런스_1막.md`의 값을 사용합니다. (튜닝하기 쉽게 변수로 빼두면 좋습니다. *단 개발 중 튜닝한 코드값이 생기면 `STATUS.md`·기획서를 그에 맞춰 갱신 — 코드가 정답.*)
4. **각 단계 끝에 "어떻게 실행/확인하는지" 알려주세요.** 개발자가 코딩 초보라, 만든 걸 *직접 실행해보는 방법*을 매번 짚어주세요.
5. **막히면 멈추고 설명.** 에러가 나거나 모호하면, 추측으로 밀어붙이지 말고 개발자에게 상황을 쉽게 설명하고 물어봐 주세요.

## 🗺️ 1막 구현 로드맵 (이 순서로)

### Phase 0 — 프로젝트 뼈대
- [ ] Godot 4 프로젝트 기본 설정 (가로 모드, 해상도, 2D)
- [ ] 폴더 구조 잡기 (scenes / scripts / assets 등)

### Phase 1 — 플레이어(치즈) 기본 ★여기부터 시작
- [ ] **치즈를 화면에 띄우기** (CharacterBody2D + 임시 컬러 사각형)
- [ ] **좌우 이동** (좌우 화살표/드래그, 위아래 없음, 화면 왼쪽~2/3 구간 제한)
- [ ] **점프 = 회피** (탭/스페이스, 적 통과시키지 않음 — 단순 점프 모션)
- 참고: 전투 공간은 *단일 화면 고정*(카메라 스크롤 없음). 시스템밸런스 §1.1 참조.

### Phase 2 — 적 + 전투 기본
- [ ] **적(쥐) 등장** — 오른쪽에서 왼쪽으로 전진, "걷고-멈추기" 반복
- [ ] **치즈 = 관문** — 적이 치즈에 닿으면 멈춰서 공격 (통과 못 함)
- [ ] **치즈 HP** — 유일한 실패 게이지, 0이면 게임오버. HP 게이지 바 UI
- [ ] **자동 조준 사격** — 치즈가 가까운 적을 자동으로 쏨
- 적 수치: 시스템밸런스 §3 (쥐 HP20/DMG5/이동1.0 등)

### Phase 3 — 밀기(핵심 메커니즘)
- [ ] **몸으로 밀기** — 치즈 전진 시 앞 적을 밂
  - 적 정지 중(속도0)이면 누구나 밀기 가능 / 전진 중이면 치즈 이동속도 > 적일 때만
  - 막힌 적 3마리 넘으면 못 밂
  - 미는 동안 적과 붙어 맞음(체력 트레이드오프)
- 밀기 수치: 시스템밸런스 §1.1 "밀기 구현 시작 수치" 참조

### Phase 4 — 웨이브 + 스테이지
- [ ] **웨이브 시스템** — 적이 웨이브로 등장, 다 처치하면 클리어
- [ ] **스테이지 1-1** 먼저 완성 (가장 쉬운 난이도, 쥐 소수)
- [ ] 클리어 → 다음 스테이지 흐름

### Phase 5 — 직업/스킬 (그 다음)
- [ ] 보안관 직업 (1-3 지급) — 스탯·평타
- [ ] 크리티컬, 스킬 장착 시스템
- 직업 수치: 시스템밸런스 §4

### Phase 6 이후 — 펄·호루라기·보스·상점·UI
- 기획서 순서대로 점진 확장. (펄 축복, 호루라기 동료, 보스 2종, 맥스 상점, 홈 화면 등)
