# Home Purrtect — 그래픽 스타일 감사 리포트 (2026-06-06)

> **목적**: 목표 톤(`design.md` = 1930s 고전 카툰/컵헤드)과 **현재 실제 화면**의 간극을 짚고, 가성비 순서로 통일 계획을 세운다.
> **진단 근거**: `design.md` 8원칙(SSOT) ↔ 각 화면 코드 정밀 분석 + 사용자 공유 스샷(코인 명판·명판 버튼·전리품 슬롯). *헤드리스 렌더가 이 환경에서 안 떠 화면 캡처는 코드+공유스샷으로 대체 — 화면별 실스샷 주시면 더 날카로워짐.*

**한 줄 요약**: 외곽선·색 토큰·물건화의 *뼈대*는 섰다. **결정적으로 빠진 건 ③ 빈티지 질감 한 겹과 ⑤ 여백 장식** — 이 둘이 "값싼 클립아트 vs 고급 카툰"을 가르는 축인데 현재 0에 가깝다.

## 2. 화면별 주요 이탈점

- **공통(전 화면)**: 빈티지 질감 오버레이 없음(③), 앰비언트 장식 없음(⑤). → 전역 후처리 1장이면 한 방에 해결.
- **상점(shop.gd)**: 생색 리터럴 25개(②), StyleBoxFlat 패널(⑦). 정보가 많아 "굵은 칸"화 효과 큼(④).
- **결과/클리어(hud.gd)**: 보상 패널이 StyleBoxFlat(⑦). 별·획득 영역에 장식 여지(⑤).
- **대사창(dialogue_panel.gd)**: StyleBoxFlat(⑦) — 양피지/리본 "물건"으로 갈 여지.
- **스테이지 인트로(stage_intro.gd)**: 생색 7 + StyleBoxFlat(⑦).
- **하단 HUD(bottom_hud.gd)**: 슬롯 텍스처는 적용됨. 생색 10은 대부분 modulate용(허용 범위).
- **프롤로그(prologue.gd)**: 생색 33 — 임시 비주얼(컬러박스)이라 의도된 것, 후순위.

## 3. 우선순위 실행 계획 (impact × effort)

### P1. ★전역 빈티지 후처리 오버레이 (원칙 3) — 가성비 최고
- 게임 최상단 `CanvasLayer`에 셰이더 1장: **미세 망점(하프톤) + 종이결 노이즈 + 살짝 채도↓ + 약한 비네트**.
- 강도는 아주 낮게(질감만 느껴질 정도). 전 화면·전 UI에 자동 적용 → "디지털 매끈함" 제거.
- 비용: 셰이더 1개 + CanvasLayer 1개. **변경 최소, 효과 최대.**

### P2. 여백 앰비언트 장식 (원칙 5) — 가성비 높음
- 코드 도형으로 별·X·작은 삼각 깃발 줄·집중선을 화면 빈 코너에 은은히. 재사용 `Decor` 헬퍼.
- 타이틀/결과/상점 등 휑한 여백부터.

### P3. 플랫 패널 → 물건화 통일 (원칙 7·8)
- `StyleBoxFlat` 직접생성 10+곳을 공용 "물건" 프레임(9-slice 텍스처 또는 베벨+볼트 코드)으로 교체.
- `Design.panel_box`를 베벨/볼트 포함으로 승급 → 호출처 자동 개선.

### P4. 생색 → 토큰 정리 (원칙 2·6)
- shop·stage_intro 등의 raw `Color(...)`를 `Design` 토큰 참조로. 즉흥 px → 8배수 토큰.
