# Home Purrtect — 자산 관리 & 전투 준비 (직업·스킬·동료)

> **이 문서의 역할:** 플레이어 보유물이 인벤토리·화면에서 **어떻게 관리·장착되는지** 정의한다. 특히 직업(장비)·스킬·동료 = **"소유·장착형 자산"**의 관리 모델과 **전투 준비 화면**을 한곳에 묶는다.
> **연결:** 소비형 자산(전리품·보석·소모품·장난감)은 각 도감 문서에서 다룸. 직업·적 스탯 수치 = `기획_시스템밸런스_1막.md` §2·§4, 경제·가격 = §5, 전투 준비 화면 원형 = 시스템밸런스 §3단계(브리프 §7-B).
> **표기:** "레벨"이라는 말은 플레이어에게 노출하지 않는다(등급 라벨로 표시). 본문 내부 표기는 Lv1~5 사용.
> **정합:** 직업/스킬/동료 보유·장착 상태의 SSOT = `game_state.gd`(owned_grades·equipped_grade·equipped_skills·동료). 숫자·시점이 갈리면 코드가 정답(CLAUDE.md 개발원칙 7).

## 1. 보유물은 두 부류다

| 부류 | 해당 | 성격 | 관리 위치 |
|---|---|---|---|
| **소비형 자산** | 전리품 · 보석 · 소모품 · 장난감 | **수량 있음 · 쓰면 닳음** | 인벤토리(수량). 도감 = 설명 카드 |
| **소유·장착형 자산** | 직업(장비) · 스킬 · 동료(호루라기) | **수량 없음 · 안 닳음** = "소유했나 / 장착했나" 상태 | **전투 준비 화면** |

- **소비형**은 이미 정리 완료(전리품·보석·소모품·장난감 도감). 이 중 **소모품·장난감만 전투 슬롯에 장착**(종류당 5개), 전리품·보석은 비장착(제작 재료 / 판매 / 헌납).
- **소유·장착형**은 "수집 도감"을 따로 만들지 않는다. **전투 준비 화면이 그 역할**(보고·고르는 곳)을 하고, 상세 스탯·효과는 시스템밸런스 §4를 본다. 이 문서가 그 관리 규칙을 정의한다.
- **펄 축복**은 "해금형 + 매 판 택1"이라 결은 비슷하나, **펄에게 들러 판마다 고르는 별도 플로우**(§5.5)다. 전투 준비 화면 밖. (§5 참조)

## 2. 직업(장비) 관리

**핵심 모델(확정):** 직업 등급은 **별개로 제작하는 장비**다("직업 레벨업" 폐지). *이름 없는 보안관 ≠ 떠오르는 보안관* — 따로 제작하고, **여러 등급을 동시에 소유할 수 있으며, 그중 하나를 장착**한다.

**표시 모델(제안):**
- 직업 탭은 **패밀리 단위 타일**로 보여준다: 맨몸 · 보안관 · 메이드 · 음악가 (총 4칸).
- 패밀리 타일을 누르면 그 패밀리의 **등급 줄**(이름없는→떠오르는→소문난→이름난→전설의)이 펼쳐진다.
  - **보유한 등급** = 선택(장착) 가능.
  - **미보유 등급** = 흐리게 + 제작 조건 표시.
- 보유 등급 중 **하나를 장착** → 그 패밀리의 "현재 전투력"이 된다.

**등급 라벨:** 이름없는 / 떠오르는 / 소문난 / 이름난 / 전설의 (내부 Lv1~5, 배율 1.0/1.5/2.2/3.2/4.5). UI는 별·색으로 순서 병행 표시. "레벨" 단어 미노출.

**해금·제작:**
- 맨몸(길냥이) = 시작부터 보유(등급 고정).
- 보안관 = 1-3 클리어 시 이름없는 등급 무료 지급.
- 메이드·음악가 = 1-7 상점에서 전리품+코인으로 제작(§5.2-B).
- 상위 등급 = 각자 제작(합성 재료는 추후 확정).
- 미보유 패밀리 타일은 흐림 + 해금/제작 조건 표시.

**하위 등급 처리(TBD):** 상위를 제작해도 하위 등급은 별개 장비라 인벤토리에 남는다. 기본 동작은 "패밀리당 보유 최고 등급을 장착 추천 + 하위는 보관". 하위를 팔거나 분해할 수 있게 할지는 미정.

## 3. 스킬 관리

**핵심 모델(확정):** 스킬은 **직업 귀속**, 동전으로 사서 **슬롯에 장착**, 안 닳는다. 직업당 풀 3개(1막).

**표시 모델(제안):**
- 스킬은 직업에 종속되므로, 전투 준비에서 **직업을 고르면 그 직업의 스킬 풀(3개)이 함께 표시**된다(별도 독립 탭이 아니라 선택 직업 종속).
- **보유 스킬** = 산 것(영구). **슬롯**에 끼운다.
- **슬롯 수 = 장착한 등급에 달림**: 2-2-3-3-4 (이름없는·떠오르는=2 / 소문난·이름난=3 / 전설의=4).
- **슬롯 < 보유**면 *골라 끼우는 선택*이 생긴다(1막 후반: 3개 보유 / 슬롯 2 → 2개 선택).

**판매 시점:** 1번째 1-9 / 2번째 1-15 / 3번째 〔확정 필요〕.
> ⚠️ **[기획 충돌 — 확정 필요]** 3번째 스킬 판매 시점: 이 문서 초안 = **1-17**, 시스템밸런스 §2.4·§4·해금 타임라인 = **2막(라쿤, Lv3 슬롯부터)**. 둘 중 하나로 통일 필요. (시스템밸런스 논리: 3번째 슬롯은 소문난 등급=Lv3에서 열려 사실상 2막 → 1막 1-17에 팔아도 끼울 슬롯이 없음. 1-17 판매로 가려면 1막 후반 슬롯 정책도 같이 손봐야 함.)

**귀속 단위 — 확정 필요한 핵심 포인트:** 스킬이 "**패밀리 귀속**"인지 "**등급별 귀속**"인지.
- **제안 = 패밀리 귀속.** "보안관 경고 사격"을 한 번 사면, 보안관 등급이 올라도(이름없는→떠오르는…) 계속 보유. **등급은 끼울 수 있는 슬롯 수만 바꾼다.**
- 만약 등급별 귀속이면, 상위 등급을 제작할 때마다 스킬을 다시 사야 해서 너무 가혹 → 패밀리 귀속이 맞다고 봄.
- ✅ **코드 현황 = 패밀리 귀속**(`game_state.gd` `equipped_skills`가 직업(job) 키 기준, 등급 무관). 제안과 일치 — 사실상 확정.

## 4. 동료(호루라기) 관리

- **동료 호출 슬롯 1개 · 매 판 택1.** 보유한 호루라기 중 하나를 장착.
- **획득 = 만남(공짜 이벤트) + 호루라기(맥스 구매).** 친구가 됐어도 부르는 도구는 사야 함(§5.5-B).
- 1막 2종: **비둘기(1-13 만남) · 치와와(1-16 만남).** 〔코드 SSOT 기준 정정 — `COMPANIONS` dove meet 13 / chihuahua meet 16. 초안의 "치와와 1-13·비둘기 1-16"은 뒤바뀐 표기였음.〕

## 5. 펄 축복 (별도 플로우 — 참고)

- **출격 전 펄에게 들러 그 판 한정 1개 택**(매 판 무료). 전투 준비 화면이 아니라 **펄 화면**에서 고른다.
- 성격 = **해금형(소유) + 매 판 택1.** 막 진행·호감도로 축복 종류가 늘어남(§5.5).
- "소유·택1"이라는 점은 장착형과 결이 같지만, *판마다·무료·펄 화면*이라 관리 흐름이 달라 여기선 분리해 둔다. (추후 전투 준비 화면에 통합할지는 §7 참조)

## 6. 전투 준비 화면 (통합)

**원칙(확정): 마지막 세팅 기억 + 선택적 변경.**
- 마지막 출격 세팅을 저장 → 홈에서 **[출격]하면 그대로 바로 전투**. 안 바꿀 거면 전투 준비에 안 들러도 됨.
- 바꾸고 싶을 때만 [전투 준비]에 들러 변경 → 그게 다시 "마지막 세팅"으로 저장.

**4개 탭:**
| 탭 | 하는 일 | 근거 |
|---|---|---|
| ① 직업 | 패밀리 택1 + 보유 등급 택1 | §2 |
| ② 스킬 | 선택 직업의 보유 스킬을 슬롯(2~4칸)에 장착 | §3 |
| ③ 소모품·장난감 | 슬롯 2~3칸에 종류 배치(소비형, 종류당 5개 자동충전) | 소모품·장난감 도감 |
| ④ 동료 | 보유 호루라기 중 택1 | §4 |

**저장되는 "마지막 세팅":**
- 선택 직업(패밀리) + 장착 등급
- 직업별 스킬 슬롯 배치
- 소모품·장난감 슬롯 배치(*수량은 인벤토리 재고 따라 자동 충전*, §소모품도감)
- 동료 1종

**구현 현황 메모:** 시스템밸런스 §3단계 기준 — 직업 탭은 실작동(직업 택1 + 마지막 세팅 저장/로드), 소모품·스킬·동료 탭은 자리만(placeholder), 실제 장착·사용은 후속 단계에서 연결. 이 문서는 그 후속 단계의 설계 청사진.

## 7. 미정 · 확정 필요

- **스킬 3번째 판매 시점** — 이 문서 초안 1-17 vs 시스템밸런스 2막(라쿤·Lv3 슬롯). → **둘 중 하나로 확정 필요**(§3 충돌 박스). 1-17로 가려면 1막 후반 슬롯 정책도 같이 조정.
- **스킬 귀속 단위** — 패밀리 귀속(제안=코드 현황과 일치) vs 등급별 재구매. → **패밀리 귀속으로 사실상 확정.** (§3)
- **하위 등급 장비 처리** — 보관만 / 판매 / 분해 환급 중 무엇. (§2)
- **펄 축복 위치** — 펄 화면 별도 유지(현재) vs 전투 준비 화면 ⑤탭으로 통합. (§5)
- **소유·장착형 설명 카드** — 직업·스킬에 짧은 플레이버 카드가 필요한지. 현재는 전투 준비 화면 + 시스템밸런스 §4로 충분하다고 봄(별도 도감 안 만듦).
- 위 결정들이 정해지면 코드 SSOT(`game_state.gd`: 직업/등급/스킬 보유·장착 상태) 구조에 반영.
