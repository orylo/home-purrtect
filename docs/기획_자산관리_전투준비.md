# Home Purrtect — 자산 관리 & 전투 준비 (직업·스킬·동료)

> **이 문서의 역할:** 플레이어 보유물이 인벤토리·화면에서 **어떻게 관리·장착되는지** 정의한다. 특히 직업(장비)·스킬·동료 = **"소유·장착형 자산"**의 관리 모델과 **전투 준비 화면**을 한곳에 묶는다.
> **연결:** 소비형 자산(전리품·보석·소모품·장난감)은 각 도감 문서에서 다룸. 직업·적 스탯 수치 = `기획_시스템밸런스_1막.md` §2·§4, 경제·가격 = §5, 전투 준비 화면 원형 = 시스템밸런스 §3단계(브리프 §7-B).
> **표기:** "레벨"이라는 말은 플레이어에게 노출하지 않는다(등급 라벨로 표시). 본문 내부 표기는 Lv1~5 사용.
> **정합:** 직업/스킬/동료 보유·장착 상태의 SSOT = `game_state.gd`. ⚠️ **§2 직업 등급 모델은 "합성 승급(직전 소모)"으로 개정 — 현재 코드(별개 동시 보유)와 다름 → 코드 리팩터 대기([코드-기획 불일치], STATUS 기록).**

## 1. 보유물은 두 부류다

| 부류 | 해당 | 성격 | 관리 위치 |
|---|---|---|---|
| **소비형 자산** | 전리품 · 보석 · 소모품 · 장난감 | **수량 있음 · 쓰면 닳음** | 인벤토리(수량). 도감 = 설명 카드 |
| **소유·장착형 자산** | 직업(장비) · 스킬 · 동료(호루라기) | **수량 없음 · 안 닳음** = "소유했나 / 장착했나" 상태 | **전투 준비 화면** |

- **소비형**은 이미 정리 완료(전리품·보석·소모품·장난감 도감). 이 중 **소모품·장난감만 전투 슬롯에 장착**(종류당 5개), 전리품·보석은 비장착(제작 재료 / 판매 / 헌납).
- **소유·장착형**은 "수집 도감"을 따로 만들지 않는다. **전투 준비 화면이 그 역할**(보고·고르는 곳)을 하고, 상세 스탯·효과는 시스템밸런스 §4를 본다. 이 문서가 그 관리 규칙을 정의한다.
- **펄**은 전투 준비 화면 밖, 따로 만나러 가는 독립 공간(§5).

## 2. 직업(장비) 관리

**핵심 모델(확정):** 직업 등급은 **한 단계씩 합성으로 승급하는 장비**다("직업 레벨업" 폐지). 다음 등급 = **직전 등급 장비 + 추가 재료(+코인)** 로 합성하며, 이때 **직전 등급 장비는 재료로 소모돼 사라진다.** (예: 거리 악사 + 재료 → 연주자, 거리 악사 소모.)

**보유·제작 규칙(확정 — 한 규칙으로 통일):**
- **각 등급은 0개 아니면 1개.** 같은 등급을 중복으로 쌓지 않는다.
- **보유 여부 = 제작 가능 여부:** 그 등급을 *보유 중이면 제작 잠금*, *미보유면 제작 가능.* (이미 가진 걸 또 만들 수 없음.)
- 따라서 한 사슬이 이렇게 돈다: 거리 악사 제작 → (보유, 제작 잠금) → 연주자 합성(거리 악사 소모) → 거리 악사 칸 다시 빔 → 필요하면 거리 악사 **재제작 가능.**
- **모든 등급 레시피는 영구.** 소모됐어도 언제든 다시 만들 수 있다(레시피가 사라지는 게 아니라, 그때 들고 있던 장비 1개가 소모될 뿐).
- → 상위로 갈수록 "사슬을 다시 밟아 올라가는" 누적 비용이 커짐(상위 등급의 무게). 반복 부담은 합성 재료·코인 양으로 조절.

**표시 모델(제안):**
- 직업 탭은 **패밀리 단위 타일**로 보여준다: 맨몸 · 보안관 · 메이드 · 음악가 (총 4칸).
- 패밀리 타일을 누르면 그 패밀리의 **등급 줄**(이름없는→떠오르는→소문난→이름난→전설의)이 펼쳐진다.
  - **보유한 등급** = 장착 가능 / 제작 버튼 잠김.
  - **미보유 등급** = 흐리게 + 제작(합성) 조건 표시 / 조건 충족 시 제작 가능.
- 보유 등급(보통 최고 1개)을 **장착** → 그 패밀리의 "현재 전투력"이 된다.

**등급 라벨:** 이름없는 / 떠오르는 / 소문난 / 이름난 / 전설의 (내부 Lv1~5, 배율 1.0/1.5/2.2/3.2/4.5). 패밀리별 진급 호칭은 §4(보안관: 견습→부→보안관→주→보안관장 / 메이드: 견습→초급→중급→고급→시녀장 / 음악가: 거리 악사→연주자→악장→명연주자→마에스트로). UI는 별·색으로 순서 병행 표시. "레벨" 단어 미노출.

**해금·제작:**
- 맨몸(길냥이) = 시작부터 보유(등급 고정, 합성 없음).
- 보안관 = 1-3 클리어 시 1단계(견습 보안관) 무료 지급.
- 메이드·음악가 = 1-7 상점에서 1단계(견습 메이드 / 거리 악사)를 전리품+코인으로 제작(§5.2-B).
- 2단계부터 = "직전 등급 + 합성 재료(+코인)"로 승급(합성 재료는 추후 확정).
- 미보유 패밀리 타일은 흐림 + 해금/제작 조건 표시.

## 3. 스킬 관리

**핵심 모델(확정):** 스킬은 **직업 귀속**, 동전으로 사서 **슬롯에 장착**, 안 닳는다. 직업당 풀 3개(1막).

**표시 모델(제안):**
- 스킬은 직업에 종속되므로, 전투 준비에서 **직업을 고르면 그 직업의 스킬 풀(3개)이 함께 표시**된다(별도 독립 탭이 아니라 선택 직업 종속).
- **보유 스킬** = 산 것(영구). **슬롯**에 끼운다.
- **슬롯 수 = 장착한 등급에 달림**: 2-2-3-3-4 (이름없는·떠오르는=2 / 소문난·이름난=3 / 전설의=4).
- **슬롯 < 보유**면 *골라 끼우는 선택*이 생긴다(1막 후반: 3개 보유 / 슬롯 2 → 2개 선택).

**판매 시점:** 1번째 1-9 / 2번째 1-15 / 3번째 1-17 (맥스). 셋 다 1막 판매 — 슬롯 2개라 3개 중 2개 장착(3번째 슬롯은 Lv3=2막).

**귀속 단위(확정): 패밀리 귀속.** "보안관 경고 사격"을 한 번 사면, 보안관 등급이 바뀌어도(승급·소모·재제작과 무관) 계속 보유한다. **등급은 끼울 수 있는 슬롯 수(2~4)만 바꾼다.** (등급별 귀속이면 승급·재제작마다 스킬을 다시 사야 해 가혹 → 패밀리 귀속.) 합성으로 거리 악사가 소모돼도 "음악가 스킬 보유"는 그대로 유지된다. (코드 `equipped_skills`가 직업 키 기준 = 일치)

## 4. 동료(호루라기) 관리

- **동료 호출 슬롯 1개 · 매 판 택1.** 보유한 호루라기 중 하나를 장착.
- **획득 = 만남(공짜 이벤트) + 호루라기(맥스 구매).** 친구가 됐어도 부르는 도구는 사야 함(§5.5-B).
- 1막 2종: **비둘기(1-13 만남) · 치와와(1-16 만남).** 치와와가 성능이 더 좋아 뒤(1-16)에 배치. (코드 `COMPANIONS` dove meet 13 / chihuahua meet 16과 일치 ✅)
- 동료 탭에서 보유 호루라기 중 택1.

## 5. 펄 (별도 공간 — 전투 준비 화면 아님 · 확정)

펄은 **전투 준비 화면에 통합하지 않고, 따로 만나러 가는 독립 공간**으로 둔다. 단순 버프 선택창이 아니라 *미연시형 관계 쌓기 + 헌납 시스템*이 핵심이라, 기능적 세팅(장비·스킬·소모품·동료)과 결이 달라 분리하는 게 맞다.

**펄 공간이 품는 것 3종:**
1. **출격 축복 택1** — 그 판 한정 1개(매 판 무료). 막 진행·호감도로 종류 늘어남(§5.5).
2. **보석 헌납 → 호감도** — 보석을 바쳐 호감도↑("팔까 바칠까" 딜레마의 한 축).
3. **관계 이벤트** — 호칭·대사 톤 변화, 컷신(눈빛→뽀뽀), 연인·데이트로 이어지는 로맨스 서브플롯.

→ "펄을 만나러 간다"가 곧 *축복 고르고 / 보석 바치고 / 관계 진전*을 한자리에서 하는 흐름. 전투 준비 화면(기능)과 펄 공간(관계+축복+헌납)은 **별개 동선.**

성격상 펄 축복도 "해금(소유) + 매 판 택1"이라 장착형과 닮았지만, *판마다·무료·펄 공간*이라 이 문서의 전투 준비 관리 모델과는 분리해 다룬다. 상세 = 시스템밸런스 §5.5.

## 6. 전투 준비 화면 (통합)

**원칙(확정): 마지막 세팅 기억 + 선택적 변경.**
- 마지막 출격 세팅을 저장 → 홈에서 **[출격]하면 그대로 바로 전투**. 안 바꿀 거면 전투 준비에 안 들러도 됨.
- 바꾸고 싶을 때만 [전투 준비]에 들러 변경 → 그게 다시 "마지막 세팅"으로 저장.

**4개 탭:**
| 탭 | 하는 일 | 근거 |
|---|---|---|
| ① 직업 | 패밀리 택1 + 보유 등급 택1 | §2 |
| ② 스킬 | 선택 직업의 보유 스킬을 슬롯(2~4칸)에 장착 | §3 |
| ③ 소모품·장난감 | 슬롯 2~3칸에 종류 배치(소비형, 종류당 5개 자동충전) | 소모품·장난감 도감 |
| ④ 동료 | 보유 호루라기 중 택1 | §4 |

**저장되는 "마지막 세팅":**
- 선택 직업(패밀리) + 장착 등급
- 직업별 스킬 슬롯 배치
- 소모품·장난감 슬롯 배치(*수량은 인벤토리 재고 따라 자동 충전*, §소모품도감)
- 동료 1종

**구현 현황 메모:** 시스템밸런스 §3단계 기준 — 직업 탭은 실작동(직업 택1 + 마지막 세팅 저장/로드), 소모품·스킬·동료 탭은 자리만(placeholder), 실제 장착·사용은 후속 단계에서 연결. 이 문서는 그 후속 단계의 설계 청사진.

## 7. 미정 · 확정 필요

- ~~스킬 귀속 단위~~ → **패밀리 귀속으로 확정.** 한 번 산 스킬은 같은 패밀리면 승급·재제작과 무관하게 유지, 등급은 슬롯 수만 결정. (§3)
- ~~하위 등급 장비 처리~~ → **합성 승급으로 확정.** 하위는 승급 시 소모되고, 레시피는 영구라 언제든 재제작. "남아도는 하위" 문제 자체가 사라짐. (§2)
- **합성 재료** — 2단계부터의 등급별 합성 재료·코인 양 미정(상위일수록 무게, 단 반복 부담 조절). 별도 합성표로 정할 것.
- ~~펄 축복 위치~~ → **펄은 따로 만나러 가는 독립 공간으로 확정**(전투 준비 화면 통합 안 함). 축복 택1 + 보석 헌납 + 관계 이벤트를 그 공간에서. (§5)
- **소유·장착형 설명 카드** — 직업·스킬에 짧은 플레이버 카드가 필요한지. 현재는 전투 준비 화면 + 시스템밸런스 §4로 충분하다고 봄(별도 도감 안 만듦).
- **★코드 반영 대기:** "등급은 0/1개·보유=제작잠금·합성 시 직전 소모" 규칙은 **현재 코드(별개 동시 보유)와 다름** → `game_state.gd`(owned_grades·craft_grade) 리팩터 + 세이브 마이그레이션 필요. 합성 재료표 확정 후 진행. (STATUS [코드-기획 불일치])
