# 추출 침입자 스프라이트 (디자이너 참고용)

> 게임은 검은 계열을 **회색 프레임 + `enemy_darken.gdshader`** 로 런타임 생성한다(파일 없음).
> 이 폴더는 그 셰이더를 동일 공식으로 재현해 **검은 3종을 실제 PNG로 추출**한 참고본.
> ★게임 에셋 아님(여기 두면 Godot 임포트 안 됨). 트레이싱·도감·기획 참고용.

- `black/` `black_roller/` `black_thrower/` — 회색 3종에 darken 적용한 전 프레임(idle/walk/attack/hit).
- `_침입자_대조표.jpg` — 전 침입자 한눈에(보스 2종은 아직 코드 placeholder=색 원).

darken 공식: 무채색(털)+밝지않음 픽셀만 ×0.40 / 흰 손·눈·색깔 장비는 보존.
